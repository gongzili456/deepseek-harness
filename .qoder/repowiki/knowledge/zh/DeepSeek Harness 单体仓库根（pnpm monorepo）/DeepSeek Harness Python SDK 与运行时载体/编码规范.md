- 配置对象统一使用 `@dataclass(slots=True)` 定义（如 `HarnessConfig`、`DeepSeekHarnessConfig`、`Notification`、`IncomingRequest`），以减少内存占用。
- 对外 API 通过 `__init__.py` 显式 re-export 白名单（`__all__`），内部模块保持私有。
- 运行时通信采用 JSON-RPC 2.0 行协议：每条消息以 `json.dumps(..., separators=(',', ':')) + '\n'` 序列化后写入 stdin，读取端按行 `json.loads` 解析。
- 并发安全通过 `threading.Lock` 保护共享状态（响应等待器、通知订阅者、会话父子关系表），并使用独立 daemon 线程处理 stdout/stderr。
- 错误分层：所有异常继承自 `HarnessError`，并按传输层（`TransportClosedError`）、协议层（`SdkProtocolError`）、JSON-RPC 层（`JsonRpcError`）细分。
- 运行时可执行定位遵循“显式覆盖 > 环境变量 > 自动探测”的优先级：`resolve_bundled_launch_args(mode)` 优先使用传入 mode，其次读 `DSH_RUNTIME_MODE`，最后自动查找 exe。
