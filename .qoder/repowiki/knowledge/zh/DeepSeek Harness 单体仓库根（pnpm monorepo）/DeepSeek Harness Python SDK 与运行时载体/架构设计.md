模块由两个相互依赖的 Python 包组成：
- `python/sdk`（`deepseek_harness`）：面向用户的同步 SDK。`api.py` 暴露高层 `DeepSeekHarness`/`Session`/`RunResult`，内部委托给 `client.HarnessClient`；`client.py` 使用 `subprocess.Popen` 启动运行时进程，通过 stdin/stdout 按行发送 JSON-RPC 2.0 消息，并用独立的 reader/stderr 线程、`queue.Queue` 和 `threading.Lock` 实现请求-响应、通知订阅与子会话树追踪；`models.py` 定义 Pydantic 数据模型（`InitializeResponse`、`ServerInfo`、`Notification`、`IncomingRequest`），`errors.py` 定义 `HarnessError` 及其子类。
- `python/sdk-runtime`（`deepseek_harness_runtime`）：纯运行时载体包，不包含业务逻辑，仅提供 `resolve_bundled_launch_args()` / `bundled_runtime_path()` / `bundled_default_config_path()` 等函数，根据当前平台在 `runtime/dsh-jsonrpc-agent-pkg-<plat>-<arch>` 单文件可执行或开发期 `node/` 闭包之间选择启动参数，并通过 `DSH_CORDIS_CONFIG` 注入默认 `cordis.yml` 配置。
- 依赖方向单向：SDK 依赖 runtime 包以解析可执行路径；runtime 不反向依赖 SDK。
- 构建阶段：`sdk/pyproject.toml` 将 `deepseek-harness-runtime-bin` 声明为运行时依赖，并通过 `[tool.uv.sources]` 指向同级目录做 editable 安装；`sdk-runtime/hatch_build.py` 作为 Hatch 自定义构建钩，校验 `platforms.json` 中指定的二进制已存在且可执行，强制生成带平台 tag 的 non-Python wheel，并拒绝 sdist。
