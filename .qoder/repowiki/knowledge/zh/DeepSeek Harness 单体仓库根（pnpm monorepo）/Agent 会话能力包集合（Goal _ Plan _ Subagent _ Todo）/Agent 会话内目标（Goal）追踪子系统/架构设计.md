模块以 `packages/goal/goal`（`@deepseek-ai/dsh-goal`）为核心领域包，向外暴露三个消费端插件：`tool-goal`（模型侧 `get_goal/create_goal/update_goal` 工具）、`command-goal`（人类 `/goal` 命令）、`goal-round-driver`（自动续跑驱动）。核心包内部按职责分层：`types.ts` 定义纯类型与 `SessionProjectionMap.goal` 投影键声明；`domain.ts` 扩展 `dsh-session`/`dsh-llm`/`cordis` 的事件与消息源类型；`runtime.ts` 提供 `GoalId` 品牌构造与 `GoalError` 错误码；`fold.ts` 实现严格的重放折叠器 `applyGoalEvent`/`decodeGoalChange`/`foldGoal`，对 `goal/change` 事件做版本校验、字段白名单与阶段转换约束；`index.ts` 中的 `GoalService` 继承 `TypertRemoteService`，维护 per-session 的 `WeakMap` 本地缓存，通过 `session.append('goal/change', ...)` 追加完整快照变更并触发 `agentEvents.emit('goal/changed')`，同时注册 `sessionProjections` 的 last-wins 投影用于无头装配。依赖方向单向：`tool-goal`/`command-goal`/`goal-round-driver` 仅依赖 `@deepseek-ai/dsh-goal` 的公开 API，不反向引用具体 agent loop，从而保持 goal 状态与消费策略解耦。
