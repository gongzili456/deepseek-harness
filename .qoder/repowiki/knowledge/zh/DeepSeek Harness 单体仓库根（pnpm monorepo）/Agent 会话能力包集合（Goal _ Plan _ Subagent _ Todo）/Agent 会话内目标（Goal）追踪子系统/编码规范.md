- 所有对外错误统一使用 `GoalError`（继承 `HarnessError`）并携带稳定的 `GOAL_*` 字符串 code，便于上层分类处理。
- 可变输入在进入领域层前通过独立的 `resolve*` 函数（如 `resolveObjective`、`resolveMaxGoalRounds`、`resolveBlockReason`）进行校验与归一化，失败时抛出 `GoalError`。
- 持久化变更采用「完整快照」模式：每次 `goal/change` 事件携带完整的 `GoalSnapshot`，重放折叠器通过 `version` 字段与字段白名单做严格解码，禁止未知字段。
- 阶段转换集中在 `transition` 辅助方法中，通过允许的阶段集合 `allowed: GoalPhase[]` 与目标 phase 参数声明式地表达有限状态机，避免分散的 if/else。
- 比较-设置（CAS）通过 `GoalRef { id, revision }` 传递，所有写操作先 `expectCurrent` 校验当前 ref，再递增 `revision` 写入，保证并发安全。
- 进程本地的 continuation 授权（`armed`/`disarmed`）与持久化的 `phase` 分离：`GoalService` 用 `WeakMap<Session, GoalCache>` 维护每 session 的 activation，并在 `session-start` 时重置为 disarmed。
