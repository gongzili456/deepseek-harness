模块以 `@deepseek-ai/dsh-tool-todo` npm 包形式发布，采用 Cordis 插件模式组织：
- 入口 `src/index.ts` 导出 `apply(ctx, config)`，通过 `ctx.tools.register(defineTool(...))` 注册 `todo_write` 工具，并通过 `ctx.inject(['sessionProjections'], ...)` 条件性注册 `todos` 会话投影（仅在装配了 dsh-session-projection 时激活），实现“无头组装不受影响”的可选能力。
- 配置 `Config.allowParallelInProgress` 在运行时决定是否允许多个 `in_progress` 项，仅影响描述文案与 `toTodoList` 校验逻辑，不改变持久化事件形状。
- `src/types.ts` 是纯类型源，通过声明合并向 `@deepseek-ai/dsh-session-projection/types` 注入 `SessionProjectionMap.todos`，并由 `./client` 和根 `types` 双入口零重复重导出，供 host 与浏览器端共享。
- `src/invariant.ts` 作为独立 Cordis companion（`name='tool-todo-invariant'`），通过 `ctx.invariants.register(PACKAGE_NAME, install)` 安装对 `todo/write` 事件的持久化不变量校验，并在启动时回放历史事件；其策略刻意不限制 `in_progress` 数量，以保证历史在部署收紧策略后仍可回放。
- 依赖方向单向向外：本包依赖 `@deepseek-ai/dsh-tools`、`@deepseek-ai/dsh-session`、`@deepseek-ai/dsh-invariants`、`@deepseek-ai/cordis`，被宿主通过 `dsh-agent`/`dsh-tools` 等 peer 依赖组合装配；测试位于 `tests/`，覆盖集成、投影、loader 组合与不变量场景。
