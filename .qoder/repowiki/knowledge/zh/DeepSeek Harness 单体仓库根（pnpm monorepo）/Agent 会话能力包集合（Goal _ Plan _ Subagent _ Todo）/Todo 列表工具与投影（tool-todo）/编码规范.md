- Cordis 插件统一通过导出 `name`、`inject` 以及 `apply(ctx, ...)` 函数来声明依赖与装配点，工具与 invariant 遵循同一模式。
- 跨宿主/客户端共享的类型集中在 `src/types.ts`，通过 `export type * from './types.ts'` 从多个入口零重复重导出，避免类型定义分散。
- 会话投影通过 `ctx.sessionProjections.register<{key}, Payload>({ key, schema, init, apply, view, stateVersion })` 声明式注册，并使用 zod union 表达可空初始态。
- 对 `todo/write` 事件的数据校验拆分为两层：工具层的运行时策略校验（如 `allowParallelInProgress`）与 invariant 层的持久化形状校验（不依赖部署策略）。
- 工具描述文案按策略拼接常量片段（DESCRIPTION_HEAD + PARALLEL/SINGLE + DESCRIPTION_TAIL），使模型提示与行为策略保持一致。
