本模块是 Agent 会话能力的横向组合层：goal_tracking 提供事件溯源的目标状态与续跑驱动，planning 提供可审批的计划模式状态，subagent_coordination 以核心运行时 + 多协议适配器注册 ctx.subagents 能力，todo_list 提供任务快照追加工具；它们共同依赖 @deepseek-ai/dsh-session-projection 将各自的状态变更以投影形式写入同一会话，使 UI 与上层编排能统一消费活跃/待决/子代理/待办等跨领域状态。各子模块之间不直接互相调用，而是通过共享的 session projection 与 tool-registry 接口解耦，由宿主在启动时按需装配。
