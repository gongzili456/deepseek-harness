模块由三个独立发布的 Cordis 插件包组成，按职责分层：
- tool-subagent（@deepseek-ai/dsh-tool-subagent）：核心委派工具，`apply(ctx, config)` 根据配置在 `ctx.subagents` provider 出现时动态注册名为 `subagent`（可配置）的工具；支持 `one-shot` 与 `continuable` 两种后台模式，分别通过 `jobs.start` 或 `ctx.subagents.startContinuable` 启动子任务，并通过 `ctx.systemPrompt.section` 注入背景执行提示；使用 Schemastery 校验 Config，并在挂载时对 `depthLimit`、`prepareContinuable` 等 provider 能力做前置校验。
- tool-subagent-control（@deepseek-ai/dsh-tool-subagent-control）：提供全局命名的 `send_message` 与 `interrupt_agent` 两个工具，直接调用 `ctx.subagents.followup` / `interrupt`，不绑定特定 provider，因此可与多个委派实例共享同一套控制 API；另导出 `list-agents` 辅助类型。
- tool-subagent-report（@deepseek-ai/dsh-tool-subagent-report）：仅安装到可继续子代理的 childCtx 中，通过 `ctx.subagents.registerContinuableSetup` 注册 `report` 工具及对应 system prompt section，将结果以 `wakeup` 或 `quiet` 策略回传给父代理。
依赖方向单向向下：三者均依赖 `@deepseek-ai/dsh-subagent`、`@deepseek-ai/dsh-tools`、`@deepseek-ai/cordis`，彼此之间无运行时依赖（report 仅在 devDependencies 中引用 control）。每个包遵循相同的插件契约：导出 `name`、`inject` 数组与 `apply(ctx, config?)`，并通过 `package.json` 的 `exports` 同时暴露主入口与 `./invariant` 断言入口。
