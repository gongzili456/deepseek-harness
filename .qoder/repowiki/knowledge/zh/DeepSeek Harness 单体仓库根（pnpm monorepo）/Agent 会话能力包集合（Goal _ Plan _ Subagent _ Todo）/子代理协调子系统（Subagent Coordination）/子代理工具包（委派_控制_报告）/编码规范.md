- 插件以导出 `name`、`inject` 数组和 `apply(ctx, config?)` 函数作为统一加载契约，供 Cordis Loader 发现并挂载。
- 对外暴露的配置对象使用 Schemastery 的 `z.object(...).default(...)` 定义，并在 `apply` 入口处对运行时省略值进行断言或能力检查。
- 工具通过 `defineTool` 注册，参数与输出均声明 JSON Schema，并使用 `render` 将结构化返回值转换为纯文本提示给模型。
- 工具执行前校验 `exec.agent` 是否存在，缺失时抛出明确错误以要求调用方具备父代理身份。
- 通过 `ctx.systemPrompt.section` 注入带固定 order 编号的使用指导文本，使工具说明按稳定顺序出现在系统提示中。
- 资源清理采用返回 disposer 的模式（如 `mount` 返回 `disposeTool`），并在异常路径中显式回滚已注册的 section/tool 以避免泄漏。
