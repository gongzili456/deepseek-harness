本模块采用「核心运行时 + 可插拔后端 + 上层工具」的分层编排：
- 核心运行时（subagent）定义 SubagentProvider 抽象、命名 Provider 注册表、会话投影枚举与一次性/可延续子代理的生命周期契约，并通过 ctx.subagents 暴露能力。
- 传输适配器（subagent-acp / subagent-claude-code / subagent-codex / subagent-dsh-sdk）各自实现 SubagentProvider，把 ACP、Claude Code、Codex、DSH SDK 等外部协议适配到统一接口。
- 进程内驱动（subagent-fork-in-process / subagent-spawn-in-process / subagent-in-process-driver）提供 fork（继承父会话前缀）与 spawn（全新会话）两种启动后端，复用结构化输出捕获。
- 工具包（tool-subagent / tool-subagent-control / tool-subagent-report）作为模型可调用的工具，通过 ctx.subagents 调用已注册的 Provider 完成委派、后台消息控制与报告。
所有子模块均依赖同一套 invariant.ts 约定与 types.ts 类型边界，使不同后端的子代理在工具层完全透明。
