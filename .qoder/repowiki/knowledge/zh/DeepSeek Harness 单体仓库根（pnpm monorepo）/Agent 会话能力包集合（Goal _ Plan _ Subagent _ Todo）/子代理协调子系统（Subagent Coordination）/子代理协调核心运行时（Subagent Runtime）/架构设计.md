模块以 `SubagentRuntime`（继承自 Cordis `Service`）为唯一对外服务入口，位于 `src/index.ts`，通过 `registerProvider/start/startContinuable/followup/interrupt/reportFrom/listChildren/listDescendants` 暴露统一 API。

内部按职责拆分为多个文件：
- 类型与契约：`types.ts` 定义 `SubagentProvider`/`SubagentRun`/`SubagentCapabilities`/`ContinuableCreateSpec` 等跨包共享接口；`descriptor.ts`、`descriptor-seed.ts` 维护版本化的 `subagent/descriptor` 事件词汇，作为持久化身份来源。
- 生命周期与事件：`lifecycle.ts` 产出 `LifecycleEmitter`/`ActivationObserver`，配合 `index.ts` 中 `scopeTarget` 实现按父 Agent 作用域过滤的 `subagent/start`、`subagent/end` 事件。
- 可延续子代理管理：`continuation.ts` 中的 `SubagentContinuationManager` 负责稳定 child id 分配、冷启动恢复、激活态（running/waiting/settled）推导、所有权图、向父代理投递结算通知，并通过 `prepareContinuable` 钩子与 Provider 解耦。
- 子代理发现与枚举：`list-children.ts` 基于 `sessionProjections` 合并活 session 与可选持久化存储，按投影折叠判定 one-shot/continuable 模式。
- 策略与组合：`child-agent.ts` 提供 `applyChildComposition`、`captureDelegatedPolicyOverrides`、`appendDelegatedPolicyOverride` 等将沙箱/审批策略固定到子代理边界的工具；`depth.ts` 维护单调递增的 `delegationDepth`。
- 辅助设施：`out-of-process.ts` 导出跨进程后端的通用契约（零能力声明、cwd 校验、`settleRunResult`、`subprocessRunHandle`），被 spawn/fork/acp 等独立 Provider 复用；`assistant-output.ts`、`run-settlement.ts`、`error.ts`、`invariant.ts`、`projection-types.ts`、`activation-setup-registry.ts` 分别处理助手输出折叠、结果收敛、错误码、不变量、会话投影与部署级 setup 注入。

依赖方向单向：`index.ts` → 各子模块；`continuation.ts` 仅反向声明 `ContinuationHost` 接口由 `index.ts` 注入，避免循环依赖。所有外部子系统（Agent、Session、Projection、Persistence、Jobs、UserApproval）均为 peer dependency，按需通过 Cordis `inject` 获取，使该包成为无副作用的能力接缝。
