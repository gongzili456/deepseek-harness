- 对外能力通过 `SubagentCapabilities` 布尔位声明并在 `start` 前 fail loud 校验，未声明的能力一律拒绝而非静默降级。
- Provider 通过 `registerProvider` 以 effect-scoped 方式注册，移除时自动触发 `subagent/provider-removed` 事件，新增时触发 `subagent/provider-added`。
- 所有跨进程子代理后端共享 `out-of-process.ts` 中的 `NO_START_CAPABILITIES`、`assertUsableCwd`、`resolveChildCwd`、`settleRunResult`、`subprocessRunHandle`，禁止在 Provider 内重复实现这些边界契约。
- 可延续子代理的创建贡献以数据形式返回 `ContinuableCreateSpec`，不持有 `Agent`/`AgentHandle`/回调，所有权始终由 continuation manager 持有。
- 会话枚举统一通过 `sessionProjections` 注册 `subagentTiming`/`subagentIdentity` 投影单元，并以投影折叠结果作为 one-shot/continuable 分类的唯一权威来源。
- 错误统一封装为 `SubagentError` 并附带字符串 code（如 `NO_PROVIDER`、`UNSUPPORTED_CAPABILITY`、`CONTINUATION_UNAVAILABLE`、`CANCELLED`），调用方按 code 分支而非异常类型判断。
