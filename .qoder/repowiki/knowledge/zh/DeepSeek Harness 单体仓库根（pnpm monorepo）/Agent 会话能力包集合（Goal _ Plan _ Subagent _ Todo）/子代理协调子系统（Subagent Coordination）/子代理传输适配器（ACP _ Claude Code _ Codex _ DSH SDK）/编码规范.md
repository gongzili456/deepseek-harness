- 每个包在 `src/index.ts` 同时导出 `name`、`inject`、`Config` schema、`SubagentProvider` 实现类与 `apply(ctx, config)` 注册函数，作为 Cordis 插件的标准入口。
- 配置对象使用 `@deepseek-ai/schemastery` 的 `z.object({...}).default(...)` 定义，并在 `apply` 中通过类型断言 `ResolvedConfig` 消费已填充默认值的配置。
- Provider 类固定声明 `capabilities = NO_START_CAPABILITIES` 与 `inheritsParentContext = false`，表明子代理运行于隔离子进程且不继承父会话上下文。
- 工作目录一律从 `request.parent.session.header.cwd` 派生，并通过 `resolveChildCwd`/`validateConfiguredCwd` 校验为绝对可访问路径，禁止回退到 harness 启动目录。
- 子进程终止采用两级宽限阶梯：先发送 stdin EOF 等待 `disposeEofGraceMs` 让子进程自行清理嵌套进程，再调用 `terminate()` 触发 SIGTERM→SIGKILL 的 `disposeGraceMs` 强制退出。
- 子进程错误通过 `onError(error, stopReason)` 回调下沉到 `ctx.logger.warn`，而非拒绝 `result` Promise，以遵守 seam 的 never-reject 契约。
