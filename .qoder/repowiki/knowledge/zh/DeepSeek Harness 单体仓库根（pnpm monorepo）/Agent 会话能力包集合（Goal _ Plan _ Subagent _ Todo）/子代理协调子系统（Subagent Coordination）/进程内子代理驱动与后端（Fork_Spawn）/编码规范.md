- 每个包以 `export const name` 和 `export const inject` 声明插件元数据，并通过 `apply(ctx, config)` 函数将 Provider 注册到 `ctx.subagents`。
- 配置对象使用 `schemastery` 的 `z.object({...}).default(...)` 模式定义，并在同名常量上重复声明类型与校验 schema。
- 子代理能力通过 `capabilities: SubagentCapabilities` 字面量显式声明（如 `outputSchema`、`depthLimit`、`toolFilter`、`persona`），并由 `inheritsParentContext` 布尔值区分 fork 与 spawn 的上下文继承语义。
- 进程内运行统一经由 `startInProcessRun(request, options)` 驱动，fork 传入 `{ seed }` 而 spawn 传入空对象，避免各自重复实现生命周期管理。
- 结构化输出采用「工具 + 系统提示段 + guard」三段式：在 child setup 中注册 `structured_output` 工具、注入 order 190 的指令段，并用 `tools.guard` 阻止已提交后的后续调用。
- 错误与终止原因通过集中映射函数转换（如 `toStopReason` 将 `TurnEndReason` 映射为 `SubagentStopReason`），保证上层 seam 词汇一致。
