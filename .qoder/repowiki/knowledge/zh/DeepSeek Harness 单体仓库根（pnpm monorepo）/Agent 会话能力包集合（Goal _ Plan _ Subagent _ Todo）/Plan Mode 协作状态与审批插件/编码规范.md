- 对外暴露的入口文件通过 `export type * from './types.ts'` 将纯类型从单一来源重新导出，保持 host 与 client 命名空间解耦且零重复。
- Cordis 服务通过 `static inject = [...]` 声明依赖，并使用 `ctx.inject([...], (childCtx) => { ... })` 按需激活可选子功能（如 commands、sessionProjections）。
- 会话状态变更统一通过 `session.append('plan/mode', { active })` 写入日志，并以 WeakMap<Session, {...}> 暂存 pending 意图，在 pre-step 边界或空闲时提交，保证幂等与可重放。
- 对用户交互失败（如取消评审）通过抛出带语义的错误消息（如 UserQuestionError 分支）让上层决定继续规划而非静默退出。
- 不变量校验以 companion plugin 形式提供，通过 `apply(ctx)` 返回 disposer，并在 seed 阶段遍历已有 session 事件进行回溯校验。
