- 平台能力探测统一通过 `probe(launcher)` 返回 `'full' | 'partial' | 'unusable'`，禁止用 `--version` 或环境变量做可用性判断。
- 二进制路径由 `launcherPath()` 经 `require.resolve` 解析，不存在时回退到绝对路径而非 cwd 相对路径，避免 cwd 劫持。
- 文件系统授权通过 `grantArgs({ readOnly?, readWrite? })` 生成 `--ro`/`--rw` 参数序列，flag 拼写对外部消费者不可见。
- 每个平台包通过 `prebuilds.json` 声明目标平台与产物，`scripts/build.ts` 中的 `TOOLS` 白名单表驱动编译，新增工具必须同时注册源与目标。
- 发布前钩子 `prepack` 调用 `scripts/verify-entry-lib.mjs` / `verify-launcher-binary.mjs` 校验打包产物完整性。
- 所有 CLI 行为（argv 语法、退出码、报告行）集中在 `docs/cli-contract.md` 维护，JS 与 C 两端不得各自实现解析逻辑。
