模块采用「入口 JS 包 + 多平台预构建包」的双包结构：`packages/entry` 暴露 `launcherPath()`、`grantArgs()`、`probe()` 等 JS API，通过 `createRequire` 解析 `@deepseek-ai/node-addon-landlock-run-linux-{x64,arm64}` 下的 `bin/landlock-run`；各平台包仅含 `package.json`（声明 `os`/`cpu` 字段）与 `prebuilds.json`，不引入运行时依赖。C 源码位于 `packages/entry/src/main.c`，由根级 `scripts/build.ts` 在 Linux 主机上以 `musl-gcc -static` 编译到对应平台的 `bin/` 目录，禁止交叉编译，CI 按架构 runner 作为“记录构建者”。发布流程通过 `scripts/{assemble-prebuilds,bump-release,commit-release,pack-release,publish-release,verify-*}.mjs` 串联，CLI 契约与 ABI 版本矩阵固化在 `docs/cli-contract.md` 与 `docs/support-matrix.md` 中，JS 层只负责拼装 `--ro`/`--rw` 参数并调用 `--probe` 判断 `full|partial|unusable`，所有二进制细节对消费者隐藏。
