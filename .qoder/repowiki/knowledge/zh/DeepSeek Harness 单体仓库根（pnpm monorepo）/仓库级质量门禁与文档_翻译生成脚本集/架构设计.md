该模块是仓库的横切工具层，按职责分为四类：
- 门禁编排：`run-gates.ts` 定义 `Mode` 联合（ci-primary / ci-static / ci-coverage / ci-snapshot / ci-consumers / node-compat / check-all / doc-sync 等），通过 `gatesForMode()` 组装带 `needs` 依赖图的 Gate 列表，内置有向无环图校验、周期检测与基于 `availableParallelism()` 的并发调度器，所有子命令通过 `pnpm exec` 以 shell-free 方式在子进程执行。
- 不变量校验：`package-invariants.ts`、`verify-package-invariants.ts`、`verify-built-package-invariants.mjs`、`check-workspace-constraints.ts`、`rescope-vendor.ts` 等脚本各自扫描 `packages/*/*/package.json` 或源码树，收集 `PackageInvariantViolation` 并输出可读错误；`coverage-exempt.ts` 集中声明被排除在覆盖率之外的重型测试套件。
- 文档与 API 生成：`gen-cordis-api.ts`、`cordis-core-api.ts`、`gen-client-catalog.ts`、`gen-tool-catalog.ts`、`gen-config-catalog.ts`、`gen-persistence-catalog.ts`、`gen-scoped-events.ts`、`gen-doc-graphs.ts`、`project-doc-site.ts`、`doc-typecheck.ts`、`verify-export-jsdoc.ts` 等基于 TypeScript AST 与 JSDoc 解析（`jsdoc.ts`）从 vendor 与 packages 源码生成 Markdown 片段与目录清单，配合 `scripts/fixtures/translation-prompt/` 与 `snapshots/` 中的期望数据做回归断言。
- 翻译与国际化：`translation-pairing.ts`、`translation-pairing-git.ts`、`translation-pairing-merge.ts`、`translation-brief.ts`、`verify-translation-pairing.ts`、`verify-translation-prompt.ts` 围绕 `translation-pairing.manifest.json` 维护中英双语文档配对、生成区域标记（`<!-- BEGIN GENERATED ... -->`）与 i18n sidecar 文件。
- 辅助基础设施：`slot-walk.ts`、`cordis-walk.ts`、`ts-project.ts`、`markdown.ts`、`repo-files.ts`、`session-fixture-layout.ts` 提供共享的源码遍历、TS 项目读取、Markdown 处理与 session fixture 布局工具。
依赖方向单向：具体 gate 脚本 → 共享 walk/ts/markdown 工具 → Node 标准库；gate 编排器不反向依赖具体校验逻辑，仅通过 pnpm script 名称调用。
