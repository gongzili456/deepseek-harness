- 每个质量门禁脚本同时提供实现文件与同名 `.spec.ts` 测试文件，用 vitest 对纯函数进行回归断言。
- Gate 定义统一通过 `pnpmScript(id, scriptName, { label, needs, env })` 或 `pnpmExec(id, args, options)` 构造，并以 `id` 作为依赖图中的唯一键。
- 校验类脚本返回结构化的 `Violation[]`（如 `PackageInvariantViolation`），由统一的 `format*Violation` 函数输出 repo-relative 路径与消息。
- 文档与 API 生成脚本以配置数组（如 `CORDIS_CORE_API_PAGES`）声明目标页面与源符号，再由通用渲染循环产出 Markdown。
- 翻译相关脚本将不可变清单（`translation-pairing.manifest.json`、`type-equiv.manifest.json`、`doc-budgets.manifest.json`）作为契约来源，运行时先解析再消费。
- 所有子进程调用都通过 `pnpm exec` 以 shell-free 方式启动，避免平台差异导致的 shell 行为不一致。
