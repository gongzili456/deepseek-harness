- 通过 `declare module '@deepseek-ai/cordis'` 扩展 Context 接口（如 `sessionPersistence`、`sessionProjections`）以提供类型安全的上下文服务注入。
- 持久化与投影的边界操作统一接受可选 `AbortSignal`，并在关键路径开头调用 `signal?.throwIfAborted()` 或 `observeQueuedAbort` 实现可取消的长耗时 I/O。
- 对事件数据采用先 snapshot/adopt 再持久化的模式（`snapshotJsonValue`、`snapshotSessionEvent`、`adoptSessionEvent`），确保写入的是无副作用的 JSON 副本。
- 通过自定义 Error 子类区分故障语义（如 `SessionPersistenceCorruptionError` vs `SessionFormatUnsupportedError`），并在错误消息中携带稳定上下文（id、location）。
- 投影单元必须实现纯同步的 `init/apply/view` 并以 `stateVersion` 标注结构兼容性，避免跨版本共享 state 导致缓存污染。
- 检查点策略通过 `ctx.on('...')` 监听 Cordis 事件并短路下游 next() 来实现 fail-closed 的断言式拦截。
