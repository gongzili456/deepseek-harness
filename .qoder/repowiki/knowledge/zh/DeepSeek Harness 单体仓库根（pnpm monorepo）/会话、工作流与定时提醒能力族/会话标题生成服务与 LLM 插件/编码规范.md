- 所有配置对象均通过 schemastery/zod schema 在包根导出 `Config` 常量进行静态校验，并在构造函数中用 `assertPositiveInteger` 等守卫函数做运行时断言。
- LLM 插件统一通过 `registerSessionTitleLlmProvider(ctx, config, name, automaticMode, selectMessages)` 注册，自身不直接实现 `generate`，仅负责消息筛选策略。
- 标题来源通过联合类型 `SessionTitleSource`（`fallback` | `provider` | `user`）区分，并由 `source.kind` 决定后续自动调度行为（如 `user` 来源会阻止后续自动生成）。
- 异步工作通过 revision 编号 + `AbortController` 实现 supersede 语义：新请求先 abort 旧 active 任务再递增 revision，`assertCurrent` 在每个 await 后校验一致性。
- 对外暴露的类型通过 `declare module` 扩展宿主接口（如 `Context.sessionTitle`、`SessionEventMap`、`SessionProjectionMap`），保持零运行时依赖的纯类型增强。
- 所有用户输入与 LLM 输出都经 `normalizeSessionTitle` 规范化，并以 UTF-8 字节长度（`maxTitleBytes` / `maxInputBytes`）而非字符数作为容量上限。
