- 每个工具通过 `export const name` + `export const inject = [...]` 声明依赖注入清单，并由 `export function apply(ctx, config)` 完成工具注册。
- 配置对象同时导出 TypeScript `interface` 与同名的 `schemastery` `z.object(...)` 实例，用于运行时默认值填充与类型约束。
- 工具描述与显式使用策略分别通过常量 `DESCRIPTION` 传入 `defineTool.description`，并通过 `ctx.systemPrompt.section({ name: 'tool:<name>', order, text })` 注入提示词段落。
- 非 clean 的 `WorkflowResult.stopReason` 统一通过本地 `stopReasonError` switch 函数映射为错误消息，再 throw 成 `isError` 结果，避免把引擎内部状态泄露给模型。
- 跨进程/跨 provider 边界的返回值一律经过防御性解析函数（如 `readReport`、`readRunResult`）进行字段白名单校验、归一化与字符上限检查后再使用。
- 结果渲染统一采用 `presentCall`/`presentResult` 返回 `{ card: 'generic' }`，实际文本由 `output.render` 生成并受 `maxResultChars`/`maxHandoffChars` 截断保护。
