本模块由四个彼此独立但风格一致的子目录组成，每个子目录下的每个子包都是独立的 npm 包（含独立 package.json/tsconfig.json），通过 Cordis `Context` 与 `inject`/`apply` 约定进行运行时装配。

- `packages/util/`：零依赖的基础原语库，每个子包（brand、home-paths、timeout、atomic-write、native-command、output-retention、launch-environment）均提供纯函数或极小类，并通过 `src/invariant.ts` 暴露空实现的 `InvariantInstaller` 以向 `@deepseek-ai/dsh-invariants` 登记自身包名，实现“无运行时数据但受契约检查”的纯工具模式。
- `packages/typert/`：按职责拆分为三个包——`protocol` 定义跨进程契约与 `TypertContribution` 类型；`registry` 在运行时维护 `ctx.typert` 服务（client/service/types）；`loader` 监听 Loader 的 `internal/plugin` 事件，增量扫描已挂载条目并解析其 `./typert` 导出，调用 `validateTypertManifest` 校验后注册到 registry；`generator` 是构建期库，通过 analyzer/renderer/emitter/workspace 把 TypeScript 源码编译为 TYPERT manifest，供 loader 消费。
- `packages/test-support/`：面向开发与测试的非产品包，包含 ACP 快照测试套件（acp-snapshot）、AgentLoop 前置挂载（agent-loop-testkit）、jsdom 客户端测试运行时（client-runtime）、LLM 模拟服务器（llm-mock-server）、录制回放（llm-replay）和 Loader 冒烟测试（loader-smoke）。这些包仅在 devDependencies 中引用，遵循“获得产品契约才移出 test-support”的边界约定。
- `packages/examples/`：预组装的可运行插件 bundle（acp-demo、agent-spine-demo、jsonrpc-demo），每个包通过 `src/index.ts` 暴露 `Config` schema + `apply(ctx, config)` 入口，组合 agent-spine、JSONL 持久化、ACP/JSON-RPC 传输等插件并以有序生命周期管理资源，作为仓库根 `examples/` 下 `cordis.yml` leaf 的装载目标。

依赖方向自顶向下：examples → test-support / util / typert；test-support 仅依赖 util 与 product runtime；util 不依赖任何其它包；typert 内部 generator→registry→loader 单向依赖 protocol。
