- 每个子包采用统一的三文件结构：`src/index.ts` 暴露主 API，`src/invariant.ts` 暴露 `name`/`inject`/`apply` 以向 dsh-invariants 登记包级契约，配套 `tests/` 与多语言 README。
- Cordis 插件统一通过 `export const name` 声明插件名、`export const inject = [...]` 声明依赖服务、`export async function apply(ctx, config)` 完成装配并返回 disposer。
- 配置对象一律配合一个同名的 zod schema 常量（如 `Config: z<Config>`）导出，使 schema 与类型同步且可由 Loader 自动发现。
- 跨包标识使用 brand/ 提供的 `Branded<B>` 名义类型，构造走拥有方的工厂（通常只是 cast），比较与序列化仍按普通字符串处理。
- 超时与取消统一通过 timeout/ 的 `Deadline`/`IdleWatchdog` 抽象，以 `AbortSignal` + `TimeoutReason(code, timeoutMs)` 传播原因，并由 `timeoutOf(x, code)` 反解。
- 示例包通过 `src/index.ts` 暴露 `Config` schema 与 `apply(ctx, config)` 组合多个插件，并使用 `ctx.effect` 显式声明插件生命周期顺序与 dispose 回调。
