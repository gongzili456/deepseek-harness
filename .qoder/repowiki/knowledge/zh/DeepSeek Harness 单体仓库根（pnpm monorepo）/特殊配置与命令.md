根 npm scripts 提供统一入口：`pnpm build` 并行编译 host/client 库并构建 web；`pnpm test` / `pnpm test:e2e` / `pnpm test:snapshot` / `pnpm test:web` 覆盖单元、端到端、快照与浏览器场景；`pnpm check:all` 串联全部质量门禁；`pnpm docs:dev|build` 驱动 website 子包；`pnpm dsh` 直接以 tsx 启动 apps_cli 二进制；`pnpm hygene` 执行 vendor/rescope/knip/publint/constraints/license/invariant 全量校验。
