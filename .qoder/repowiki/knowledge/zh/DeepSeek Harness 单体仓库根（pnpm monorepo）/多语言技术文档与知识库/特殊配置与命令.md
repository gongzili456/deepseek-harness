本地文档变更需运行 `pnpm run doc-sync`（含 `verify-md-wrap`、`verify-md-links`、`verify-translation-pairing`）；单对文档可用 `pnpm run verify-translation-pairing <pair>` 快速验证；修改后通过 `pnpm run verify-translation-pairing --write <pair>` 重新记录两端 blob hash；合并冲突时使用 `pnpm run resolve-translation-pairing-conflicts` 安全恢复已验证的配对记录。
