文档按主题划分为多个子目录：顶层为架构概览（architecture、module-graph、capability-seams、graph-atlas）、API 网关、配置/工具/持久化目录、开发流程、测试、Web 样式等横切主题；`subsystems/` 按系统模块（session、tools、lsp、sandbox、storage、workflow 等）提供一对一的子系统说明；`cordis-tutorial/` 是编号式分步教程（01-07），`cordis-api/` 描述 Cordis 插件 API；`cookbook/` 提供可操作的扩展实践；`postmortem/` 以 `NNNN-标题.md` 编号记录事故复盘；`user/` 面向用户的指南与开发者基础/框架/实践指南；`i18n/` 集中定义双语配对契约、翻译规则与术语表。

所有文档遵循严格的三文件配对约定：每个 `.md` 对应同目录的 `.zh.md` 与 `.i18n.yaml`（记录两端最新确认时的 git blob hash），由 `verify-translation-pairing` 门禁强制校验结构一致性（标题层级、代码块、表格行列数、列表形态、链接目标）。生成类英文文档（如 `cordis-api/inherited.md`）被显式排除在配对之外，由网站构建时直接复用英文源。CI 通过 `doc-sync` 任务统一运行 Markdown 格式检查、链接检查与翻译配对校验。
