本模块是 workspace 根下的 umbrella package（`dsh-examples`），自身不产出产物，仅通过 `package.json` 以 `workspace:*` 形式声明对全部 dsh-* 包的依赖，使 Node 解析到真实源码而非发布包。

- 按使用形态划分子目录：`acp-agent/`（ACP 自动化服务器）、`headless-agent/`（一次性 headless agent）、`jsonrpc-agent/`（Python SDK + JSON-RPC 驱动）、`mcp-memory/`（MCP 内存后端覆盖）、`web-cordis/` 与 `web-schedule/`（Web 叠加配置）。
- 每个子目录自带 `cordis.yml` 作为 Cordis 插件树清单，通过 `- id: ... / name: '@deepseek-ai/dsh-...'` 条目组装 LLM、sandbox、fs、subagent、tool、compaction、session persistence 等能力；`web-cordis/cordis.yml` 使用 `insert:` 语法以 patch overlay 方式注入到 web profile。
- 测试采用“fixture + snapshot”模式：`tests/fixtures/` 存放被测 agent 的 cordis.yml 与 driver 脚本，`tests/snapshots/<scenario>/` 存放 `input.json`、`session*.jsonl`、`stdout.expected.jsonl`、可选 `system-prompt.expected.md`/`tool-schemas.expected.json`，由 `*.snapshot.ts` 或 `*.e2e.ts` 驱动对比。
- 环境变量控制运行时行为：`DSH_SNAPSHOT` 切换 zstd 压缩为 none、`DSH_PERMISSION_MODE` 切换 sandbox 策略、`DSH_SESSION_ROOT`/`DSH_CWD`/`DSH_SYSTEM_PROMPT` 等注入 per-session 值，使同一份 cordis.yml 同时支持交互运行与快照回放。
- 依赖方向单向：示例 → 各 `@deepseek-ai/dsh-*` 包；示例之间彼此独立，无跨子目录 import。
