各子包通过 Cordis 框架的作用域（scope）与事件总线进行解耦协作：`scope` 提供作用域上下文与按作用域过滤的事件分发，被 `agent-loop`、`session`、`tools`、`system-prompt`、`agent-default-model`、`agent-tool-presentation` 共同消费；`session` 以事件溯源形式维护消息流并暴露表面投影，供 `agent-loop` 驱动循环读取/写入；`tools` 注册工具执行管线并通过 `agent-tool-presentation` 暴露模型呈现模式；`agent` 作为入口注册中心协调 `agent-loop` 发起会话，并由 `agent-default-model` 与 `system-prompt` 注入默认模型与系统提示配置。所有子包均遵循统一的 invariant 校验约定与 tsdown 构建流程，对外仅暴露最小 API 面。
