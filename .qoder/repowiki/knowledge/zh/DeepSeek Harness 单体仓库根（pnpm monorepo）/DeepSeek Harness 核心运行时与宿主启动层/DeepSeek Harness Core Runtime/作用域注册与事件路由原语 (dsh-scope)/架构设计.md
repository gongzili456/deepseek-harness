模块以 `src/index.ts` 为核心，导出 `createScope`/`scopeOf`/`scopeTarget`/`bindScopeParent`/`scopeChainOf` 等 API：通过给 Cordis Context 注入一个 Symbol 键 (`kScope`) 标记作用域，用 `WeakMap<ScopeKey, ScopeKey>` (`scopeParents`) 维护作用域键的父子链；`scopeTarget` 包装被分发对象的 `Context.filter`，使监听器仅在其标签等于或位于目标 key 的祖先链上时才能收到事件（向上继承、向下屏蔽）。`src/store.ts` 提供共享存储抽象：`NamedEntries`/`AnonymousEntries` 分别实现命名/匿名插入有序表，`ScopedLayers<L>` 管理全局层 + 精确作用域层的惰性创建、合并与回收，并通过 `ctx.effect` 将撤销动作绑定到注册上下文的生命周期。`src/invariant.ts` 作为可选的 Cordis companion 插件，在 `internal/dispatch` 钩子上依据 `scoped-events.generated.ts` 中的事件-主题解析映射，断言所有 scope-filtered 事件都通过 `scopeTarget` 派发且 carrier key 与参数暴露的主题一致。构建由 `tsdown.config.ts` 完成，将根入口与 invariant 子入口分别打包，并通过 `deps.neverBundle` 保持两个 bundle 共享同一个 `carrierKeys` WeakMap 实例。包通过 `package.json` 的 `exports` 同时暴露根入口和 `/invariant` 子路径，peer/dev 依赖 `@deepseek-ai/cordis` 与 `@deepseek-ai/dsh-invariants`。
