- 作用域标识使用不可比较的裸对象类型 `ScopeKey = object`，并通过 `WeakMap` 保存父链接与 carrier 映射，避免泄露内部键值。
- 对外暴露的受限类型采用 TypeScript brand 模式（如 `Scoped<T> = object & { readonly [ScopedBrand]: T }`），使编译期强制区分普通对象与作用域载体。
- 可撤销操作统一返回 idempotent 的 undo 函数（`NamedEntries.insert`、`AnonymousEntries.append`、`ScopedLayers.effect` 内的 generator yield），由调用方在注册上下文中管理生命周期。
- 作用域链遍历采用从子到根的单向 walk（`scopeChainOf`、`scopeTarget` 的祖先匹配），禁止反向或双向跳转，新增 parent 前执行环检测。
- 作用域层访问区分精确查找 (`peek` 不创建) 与继承视图 (`chainLayers`/`merge` 沿父链聚合)，确保自身贡献不会隐式拾取祖先层。
- 可选能力通过独立子路径暴露（`./invariant`），并以 Cordis plugin 形式（`apply`/`inject`/`name`）注册，主包不强制依赖 invariant 服务。
