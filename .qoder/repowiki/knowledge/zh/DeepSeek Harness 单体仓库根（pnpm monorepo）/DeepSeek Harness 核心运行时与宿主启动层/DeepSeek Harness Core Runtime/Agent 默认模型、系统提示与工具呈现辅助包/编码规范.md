- 所有 Service/Plugin 通过 `declare module '@deepseek-ai/cordis' { interface Context }` 扩展 Context 类型，将自身实例挂载到固定属性名（如 `agentDefaultModel`、`systemPrompt`）。
- 配置对象统一用 Schemastery (`z.object({...})`) 定义静态 Schema，并以 `static Config` 或同名导出常量暴露给上层组合器进行运行时校验。
- 注册类 API（section/context/variable/tools）返回精确的 disposer 函数，配合 `layers.effect(ctx, mutate, {label})` 实现作用域内的自动生命周期管理。
- 作用域隔离通过 `ScopedLayers` + `scopeTarget` 实现：全局注册与 scoped 注册分别存入不同层，assemble 时从远到近覆盖变量与 section。
- 可变状态通过 `source` 函数指针或 settings onChange 回调更新，读取端始终调用 `currentSelection()` 等方法获取最新值，避免持有过期闭包。
