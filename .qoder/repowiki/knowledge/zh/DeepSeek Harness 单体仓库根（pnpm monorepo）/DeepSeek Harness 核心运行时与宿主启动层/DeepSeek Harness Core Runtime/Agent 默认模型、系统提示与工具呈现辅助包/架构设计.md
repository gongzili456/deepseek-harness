本模块由三个独立的 npm 包组成，均基于 `@deepseek-ai/cordis` 的 Service/Plugin 机制挂载到宿主上下文：
- `agent-default-model`：导出 `AgentDefaultModelConfig` Service，通过 `installSettingsSection` 将默认模型（provider/model/reasoningEffort）持久化到 settings 命名空间，并在无 settings provider 时回退为组合期配置；对外暴露 `currentSelection()` 与 `saveSelection()`。
- `system-prompt`：导出 `SystemPrompt` Service，使用 `@deepseek-ai/dsh-scope` 的 `ScopedLayers` 维护全局与各作用域的 sections、contexts、toolProviders、variables 四层注册表；`assemble()` 按 order 合并、去重、校验 complete 段数量，调用 `ctx.waterfall('system-prompt/assemble')` 允许插件改写装配结果，并通过 `renderPrompt`/`renderContextSnapshot` 完成 `{{variable}}` 严格插值与文本拼接。
- `agent-tool-presentation`：以 Cordis Plugin 形式（`apply(ctx, config)` + `inject=['tools']`）在 preset 的 standing scope 上调用 `ctx.tools.presentAs(mode)` 声明 native/code/both 三种工具呈现模式，code 模式等待 `codeRuntime` 服务就绪后再注入。
依赖方向单向向外：三者仅依赖 cordis/schemastery/dsh-scope/dsh-settings/dsh-tools 等基础包，彼此之间无相互引用，各自独立发布为 `@deepseek-ai/dsh-agent-default-model`、`@deepseek-ai/dsh-system-prompt`、`@deepseek-ai/dsh-agent-tool-presentation`。
