模块以 `Session`（纯类，维护不可变追加日志）和 `SessionStore`（Cordis Service，注册在 `ctx.sessions`）为核心：`index.ts` 暴露创建/进入/宣告/分离的完整生命周期，并通过 Cordis 事件 `session/created`、`session/event`、`session/flush`、`session/disposed` 将持久化实现解耦为插件订阅模式。

内部按职责分层：
- `types.ts` 定义所有对外契约（`SessionEventMap`、`SurfaceEventType`、`SessionHeader`、`EpochHeader`、`TurnEndReasonMap` 等），是包内唯一被持久化后端直接引用的类型边界；`SESSION_FORMAT_VERSION` 作为单点版本锚点。
- `surface.ts` 维护消息可见的有序表面（append/replace 操作 + `sourceEventSeqs` 引用），提供增量折叠、替换验证、`deriveEventMessage` 投影以及 `SessionSurface` 只读视图，是模型历史推导的唯一来源。
- `preparation.ts` 通过 `SessionPreparation` 包装未发布 Session 及其 provider 状态，配合 `prepare`/`enter`/`announce` 三阶段原子生命周期，确保 fiber 卸载时按序释放。
- `request-header.ts`、`chunk-rows.ts`、`json.ts`、`repair.ts`、`invariant.ts`、`known-event-types.ts` 分别承担请求头折叠、行压缩编解码、lossless JSON 快照、崩溃修复、关系不变量注册与已知事件白名单等横切能力。

依赖方向单向向外：本模块仅依赖 `@deepseek-ai/cordis`、`@deepseek-ai/dsh-scope`、`@deepseek-ai/dsh-llm`、`@deepseek-ai/dsh-brand`、`@deepseek-ai/dsh-typert-protocol`，不反向引用任何上层 agent/loop/compaction 包；`package.json` 通过 `exports` 字段将 `./surface`、`./invariant`、`./types` 作为独立子路径导出，使浏览器端可仅引入 surface 而不携带 Node 运行时依赖。
