- 所有持久化写入的数据在进入日志前通过 `snapshotJsonValue` 做 lossless JSON 校验并深冻结，确保 `events` 返回的数组与其中嵌套对象均不可变。
- 事件类型采用 `SessionEventMap` 判别联合 + `SurfaceEventType` 子集标记的模式：非 surface 事件禁止携带 `surfaceOp`/`sourceEventSeqs`，由编译器与运行时双重约束。
- 对导入/恢复边界的对象执行所有权转移语义：`adoptSessionEvent` 原地冻结独占图，`snapshotSessionEvent` 先 `structuredClone` 再冻结，区分借用与拥有场景。
- 通过 `WeakMap<Session, SessionEntry>` 将 store 级附加状态（`announcing`、`appending`、`detachRequested`、`emitCtx`、`carrier`）与 Session 实例绑定，保持 `Session` 公共接口无 store 耦合。
- 对外暴露的枚举/字面量集中声明于 `types.ts`（如 `SurfaceOp`、`RequestHeaderReason`、`TurnEndReasonMap`），并在 `known-event-types.ts` 中以字符串集合形式同步，供外部扫描器消费。
- 通过 `declare module '@deepseek-ai/cordis'` 扩展 `Context.events` 的 `session/*` 事件签名，并以 `@dshScopeScan unsupported` 注释标记 scope 行为，使事件类型与分发策略在同一处声明。
