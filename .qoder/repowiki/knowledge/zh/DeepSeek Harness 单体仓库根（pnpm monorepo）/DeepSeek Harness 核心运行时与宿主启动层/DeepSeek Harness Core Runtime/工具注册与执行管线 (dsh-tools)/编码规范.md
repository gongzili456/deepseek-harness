- 通过 `ScopedLayers` + `ToolLayer` 实现可叠加的作用域注册：每个 scope 持有独立的 tools/restrictions/guards/mode，并在链上最近者生效。
- 对外暴露的公共 API 集中在 `src/index.ts` 的 `export { ... } from './xxx'` 重导出，子模块仅承担内部职责而不直接暴露给消费者。
- 错误采用具名 `HarnessError` 子类（如 `ToolNotFoundError`、`ToolOutputError`、`CodeRunFailedError`），统一携带 `code` 字符串以便上层策略路由。
- 所有跨边界传递的值（arguments、render/presentationMeta 返回值、最终 result）均通过 `snapshotJsonValue` 快照并 `deepFreeze`，确保不可变且 lossless JSON。
- Code Mode 的语言分派通过 `SDK_RENDERERS` 字面量表配合 `satisfies Record<CodeSdkLanguage, ...>` 约束，新增语言必须同步更新类型、表项与 flavor 常量，否则编译期失败。
- 工具输出采用 `output: { schema, render, presentationMeta? }` 契约：canonical JSON 值与 model-facing content 分离，UI 呈现由可选的 `presentCall`/`presentResult` 纯函数声明。
