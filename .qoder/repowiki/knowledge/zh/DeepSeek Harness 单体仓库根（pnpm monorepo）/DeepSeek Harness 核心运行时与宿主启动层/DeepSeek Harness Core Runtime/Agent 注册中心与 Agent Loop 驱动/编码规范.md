- 通过 Cordis `Service` 子类暴露能力，并在构造函数中通过 `ctx.effect` 注册副作用（如 setFactory、systemPrompt 变量、ownership.dispose），利用 Fiber 生命周期自动清理。
- 对外部可插拔组件使用“接口 + setFactory”模式：`dsh-agent` 定义 `AgentFactory` 接口，`dsh-agent-loop` 实现并通过 `setFactory` 注入，使接口层不感知具体循环实现。
- 生命周期采用“先 enter 再 announce”的两阶段发布：`enter()` 插入未公开条目并返回 detach 闭包，`announce()` 触发 `agent/created` 事件，失败时可安全回滚而不发出半公开事件。
- 取消通过 `AbortController` 聚合多来源信号（caller signal、owner fiber unload、factory teardown），并在关键 await 前调用 `assertLive()` 检查，确保资源在卸载路径上被正确中止。
- 通过 `AsyncLocalStorage` 维护进程内发起者作用域链，提供 `currentInitiator()` 可选读取与 `requireInitiator()` 强制读取两种风格，区分日志归属与契约性调用。
- 配置与设置项使用 `schemastery` 的 `z.object(...).default(...)` 声明式校验，并通过 `installSettingsSection` 暴露运行时可热更新的 settings namespace。
