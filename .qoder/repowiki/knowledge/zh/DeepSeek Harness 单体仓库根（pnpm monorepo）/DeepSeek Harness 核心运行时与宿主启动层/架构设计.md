本模块按三层组织：core 提供 Agent 生命周期、会话持久化、工具管线与作用域事件等运行时原语；boot 在进程入口负责 .env 分层加载、Loader 失败保护、快照感知配置解析，并组装 Cordis 插件组；host 暴露 Web 服务器与 apiproxy 网关，把 core 中的 agent、session、tools、settings、workspace 等能力以 RPC schema+Zod 校验的 HTTP API 暴露给前端。三者通过 Cordis 插件契约耦合：boot 启动时加载 host 插件，host 插件再依赖 core 的 agent-loop/session/scope 等包实现业务逻辑；apiproxy 作为跨客户端共享的边界，统一序列化 session、agent、jobs 等状态。所有子包均以 workspace:^ 形式相互引用，形成单一版本锁定的 monorepo 运行时。
