- 所有文件系统错误统一通过 `FsError` 抛出，并携带稳定的 `FsErrorCode` 字面量（如 `FS_STALE_VERSION`、`FS_SANDBOX_DENIED`、`FS_NOT_OBSERVED`），禁止返回裸字符串错误码。
- 后端以继承 `FileSystem` 抽象类的方式提供实现（`LocalFileSystem`、`SandboxedFileSystem`），通过覆盖 `writeText`/`editText` 插入策略围栏，而非修改抽象类。
- 配置对象使用 Schemastery (`z.object({...}).default(...)`) 声明并在构造时解析为 `ResolvedConfig`，默认值集中管理。
- 对外暴露的类型（`FsTargetKey`、`FsVersion`）通过 branded string 工厂函数（`FsTargetKey()`、`FsVersion()`）创建，消费者不得自行拼装。
- 每个包遵循统一的目录结构：`src/` 下按职责拆分文件（index、types、invariant、平台特定实现），`tests/` 下对应 `.spec.ts` 或 `.e2e.ts`，根目录含 README.zh.md 与 package.json。
- 沙箱模式通过 `FileSystem.sandboxMode` getter 暴露给工具层用于广告升级字段，沙箱后端覆写该属性返回部署默认模式，非沙箱后端保持 `undefined`。
