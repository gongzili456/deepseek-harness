- 执行器以继承 `ShellExecutor` 的方式实现，通过覆盖 `resolve()`/`run()`/`start()` 注入默认值、策略与沙箱逻辑，子类仅扩展边界行为。
- 配置统一通过 `static Config: z<...>` 静态属性声明，并使用 `installSettingsSection` 将配置注册到 `settingsNamespace('shell')`，支持运行时热更新。
- 前台 `run()` 返回 `ShellRunResult` 而非抛错，非零退出、超时、abort 均以结果字段（`exitCode`/`timedOut`/`aborted`）表达，仅基础设施失败才 reject。
- 后台 `start()` 返回 `ShellProcess`，其 `readOutput()` 采用增量消费（offset 推进）并在 lossy 时附带 spill 路径，`done` 永不 reject 而是 settle 为 `killed`。
- 沙箱执行器在 `onProcessDone` 钩子中根据 stderr/退出码判定 denial 与 runnerFailed，并将 `ShellSandboxInfo` 回填到 `proc.sandbox`，使 foreground/background 路径共享同一份事实。
- 模型工具通过 `defineTool` 注册，参数 schema 动态包含可选的 `run_in_background` 与 `sandbox_permissions`/`justification` 字段，并在 `execute` 中先走 `approveEscalation` 再构造 `ShellExecRequest`。
