模块以 `shell/` 包定义跨实现的 `ShellExecutor` 抽象服务（`ctx.shell`），声明 `ShellExecRequest` → `resolve()` → `ShellExecSpec` → `run()`/`start()` 的执行契约以及 `ShellProcess` 增量输出语义；所有具体执行器都继承该基类。
- 执行器实现分层：`bash-local/` 通过 `ctx.subprocess` 以 `bash -c` 运行命令，负责超时、信号、输出截断与 spill 文件、进程组 SIGTERM→SIGKILL 升级；`pwsh-local/` 在 Windows 上复用相同模式但使用 PowerShell 行为；`bash-sandbox/` 与 `pwsh-sandbox/` 分别继承对应 local 执行器，通过 `ctx.sandbox.confine()` 包装 argv 并注入 per-call `SandboxExecutionPolicy`，在 `onProcessDone` 中根据退出码/stderr 判定 denial/runnerFailed 并回填 `result.sandbox`。
- 模型工具层：`tool-bash/` 与 `tool-pwsh/` 消费 `ctx.shell`，注册 `bash`/`pwsh` 工具，处理前台/后台调用、`run_in_background` 与 `ctx.jobs` 集成、sandbox 权限提升审批（`approveEscalation`）、系统提示注入以及结果渲染（exit status 解析、终端卡片呈现）。
- 共享环境：`shell-env/` 提供 `DSH_*` 环境变量收集（`ctx.shellEnv`），被工具层在执行前合并进请求。
- 依赖方向单向向下：tool-* → shell 抽象 + shell-env；*-sandbox → *-local → shell 抽象；所有实现均不反向依赖工具层，由上层 `cordis.yml` 选择具体 provider 组合。
