- 所有子进程生命周期对象（普通 handle 与 terminal handle）在服务构造时注册 Cordis effect 钩子，在宿主退出或 dispose 时统一回收，避免孤儿进程。
- 子进程环境一律通过 `scrubbedParentEnv()` 清洗后再合并调用方显式传入的 `env`，敏感键（含 KEY/PASSWORD/SECRET/TOKEN）与 `DSH_*` 命名空间默认被剔除，仅显式覆盖可放行。
- 错误消息统一以 `subprocess-local:` 或 `subprocess:` 前缀开头，便于在日志中区分来源包。
- 对外异步 API 即使底层是同步操作（如 node-pty write/inspect）也返回 Promise，保持远程实现与本地实现一致的 promise 语义。
- 测试通过 `SpawnInternals` 注入 spillDir、taskkill、platform、linuxProcessGroupHasLiveMembers 等内部钩子，使平台与 I/O 行为可在单元测试中确定性替换。
- 类型与运行时分离：`subprocess` 包只导出类型与抽象基类，具体实现全部放在 `subprocess-local`，通过 `peerDependencies` 声明而非直接耦合。
