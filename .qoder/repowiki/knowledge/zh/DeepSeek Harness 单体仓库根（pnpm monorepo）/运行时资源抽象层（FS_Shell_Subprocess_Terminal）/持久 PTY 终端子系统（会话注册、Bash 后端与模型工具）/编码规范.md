- 通过 Cordis 插件模式组织扩展点：后端与工具均导出 `name`、`inject` 数组和 `apply(ctx, config)` 函数，由宿主在启动时调用完成注册。
- 所有对外暴露的错误统一派生自自定义类（如 `TerminalError`、`TerminalBackendCleanupError`），并携带稳定的字符串 `code` 字段以便机器识别。
- 会话 ID 使用 `Branded<'TerminalSessionId'>` 配合 `TerminalSessionId(value)` 工厂进行品牌化强类型封装，禁止直接传递裸字符串。
- 资源生命周期通过 `ctx.effect` / `owner.ctx.effect` 注册清理回调，确保 Agent 销毁或服务 dispose 时自动中止 pending spawn 并关闭所有 session。
- 工具输入与输出使用 `schemastery` 的 `z.object(...)` 声明式 schema，并在 `output.schema` 中用 `oneOf`/`const` 精确描述多态返回结构。
- 模型可见的输出统一经过 `finalizeContent` 钩子结合 `boundTerminalText` 进行最大字节数截断，避免单次响应过大。
