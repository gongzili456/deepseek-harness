本模块由三个并列的子域组成，各自以独立 npm 包形式发布：
- `packages/client/*`：浏览器侧 dsh GUI 插件集合，按职责拆分为 connection（HTTP/WebSocket RPC 桥、loopback 主机发现）、runtime（无 React 的数据对象层：ConnectionController/SessionManager/Session 及 zustand+immer store 引擎）、web-react（React 绑定层：SessionProvider、slot 渲染器、uSES 适配器）、locale/hmr/modules/schema-form 等横切能力，以及大量 `ui-*` 插件包（conversation、tool、sidebar、settings、workspace 等），每个插件通过 `ctx.slots.register` 在 `apply` 中声明 slot 贡献，遵循 AGENTS.md 规定的四层依赖方向：presentation → web-react → runtime → connection，禁止反向引用。
- `packages/web/*`：面向宿主/工具的浏览器网络能力，包括 `web`（类型定义）、`web-fetch-http`（带重定向策略的 fetch provider）、`web-search-deepseek/exa/perplexity`（各搜索引擎 provider）以及 `tool-web`（将 web_search/web_fetch 注册为 Cordis 工具，注入 tools/web/systemPrompt 服务）。AGENTS.md 强制所有携带凭据的请求拒绝自动跟随重定向。
- `packages/hooks/*`：hook 桥接子系统，`hook-protocol` 提供共享的匹配器、命令执行、输出合并、事件追加与 detached run 等 wire 协议原语；`hooks-claude-code` 与 `hooks-codex` 分别把外部 shell hook 方言映射到 harness 的拦截扩展点，作为普通 Cordis plugin 挂载。

构建方面，client 子包统一使用 tsdown + `tsdown.config.ts` 生成 `lib/client.js` 供 cordis 加载；connection 包额外维护 `tsconfig.client.json`/`tsconfig.host.json` 双目标；所有包均附带 `README.i18n.yaml` 多语言文档与 `tests/` 套件。
