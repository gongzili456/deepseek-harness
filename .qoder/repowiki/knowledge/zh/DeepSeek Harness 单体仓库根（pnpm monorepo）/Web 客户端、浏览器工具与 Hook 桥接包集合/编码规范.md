- 每个 client 插件包遵循统一的目录结构：`src/index.ts` 暴露 `apply`/`inject`/`Config`，`src/invariant.ts` 提供断言辅助，`src/client/` 存放浏览器端实现，并通过 `tsdown.config.ts` 用 `clientBundle` 打包。
- UI 插件仅通过 `ctx.slots.register({ name, children?, store?, inject? }, Component)` 注册贡献，禁止模块级副作用；slot 命名采用 `<domain>.<entry>.<hole>` 路径形式。
- 组件 props 严格使用四份 share 派生类型（PropsRuntime/PropsRenderSlots/PropsStore/注入面），业务数据不手写成员，组件内不直接订阅外部源，而是通过框架 hooks 或 store actions 获取。
- 数据对象层（runtime）禁止 import React，所有会话/连接/事件窗口状态集中在 ConnectionController→SessionManager→Session 链上，store 产物仅为裸 observable 源，不含 hook 成员。
- web 侧 provider 包（web-search-*、web-fetch-http）统一通过 `index.ts` 暴露 provider 工厂，并在 `policy.ts`/`provider.ts` 中集中处理凭据与安全策略（如拒绝重定向）。
- hook 桥接包（hooks-claude-code、hooks-codex）复用 `hook-protocol` 的 matcher/runner/merge/events 原语，各自只负责方言特定的 payload 映射与环境规则，不重复实现协议逻辑。
