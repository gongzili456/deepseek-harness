新增 client 插件需同时完成三处注册：`tsconfig.client.json` references、`packages/bundle/web-app/cordis.patch.yml` 中的 `dsh.client` 行、以及 `packages/bundle/web-app/package.json` 依赖；构建后需运行 `pnpm --filter <pkg> bundle` 再生成 `lib/client.js` 才能被 cordis 加载。GUI 改动走 `pnpm run test:gui`，可见 UI 输出变更需额外跑 `DSH_SNAPSHOT=replay pnpm run test:web`。
