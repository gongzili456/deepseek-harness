本模块由三个并列的 npm 包组成，分别承担不同边界职责：
- `packages/extensions/cordis-host-runner`（`@deepseek-ai/dsh-cordis-host-runner`）：Host 侧动态插件注册表与生命周期管理，通过 `DynamicCordisRunnerService`（继承自 `TypertRemoteService`）暴露 define/run/stop/inspect/invoke 等 RPC 方法，使用 `sandbox.ts` 在 VM 中执行宿主代码并启动 Cordis Fiber，配合 `registry.ts`、`lifecycle.ts`、`guard.ts`、`inspect-registry.ts` 维护插件版本、审批流、Client 同步与 Inspect Provider 目录。
- `packages/extensions/cordis-client-runner`（`@deepseek-ai/dsh-cordis-client-runner`）：浏览器侧对应半程，通过 `client/orchestrator.ts`、`client/runtime.ts`、`client/providers.ts`、`client/slot-catalog.ts` 加载宿主下发的 client 代码、建立 Provider/Slot/事件通道，并通过 `client/guard.ts` 做沙箱准入校验。
- `packages/extensions/tool-cordis`：向模型暴露 `cordis_inspect_*`、`cordis_define`、`cordis_run`、`cordis_stop`、`cordis_undefine` 等工具，封装 Host Runner 调用并以 `present.ts` 渲染结果，同时通过 `agent/pre-step` 钩子把 `@pluginId` 引用注入系统提示。
- `packages/extensions/ui-cordis`：纯 UI 插件，仅导出空 `apply()` 占位，实际 React 组件位于 `src/client/`，通过 `package.json.dsh.client.inject` 注入到浏览器面板。
- `packages/api/gateway`：基于 `TypertGatewayService` 将 Cordis Services + Typert providers 暴露为 `/api` RPC 路由，支持 strict descriptor 与 SRC 回退解析、lookup/context 参数绑定、JSON 安全校验与 `AbortSignal` 取消传播。
- `packages/api/remotes`：Host BFF 入口，集中声明允许转发的远端事件白名单（`API_REMOTE_FORWARDED_EVENTS`），并通过 `agent-lookup.ts` 暴露子代理会话查找能力。
- `packages/acp/acp`：基于 `@agentclientprotocol/sdk` 的 JSON-RPC stdio 服务器，实现 initialize/newSession/prompt/cancel 协议，监听 `session/event`、`approval/request`、`agent/error` 等事件，将 Harness 内部 Agent 会话映射为 ACP 会话，并通过结构探测 `ContinuableDrain` 完成可延续子代理的 child-first 清理。
依赖方向单向向外：tool-cordis → cordis-host-runner；ui-cordis 仅依赖主题与 slots；gateway/remotes 依赖 dsh-typert-protocol 与 dsh-session；acp 依赖 dsh-agent/dsh-session/dsh-llm，不反向依赖 extensions。
