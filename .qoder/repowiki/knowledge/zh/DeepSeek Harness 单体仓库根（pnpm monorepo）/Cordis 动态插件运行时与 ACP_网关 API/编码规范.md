- 所有宿主侧服务类继承 `TypertRemoteService` 或 `Service`，通过 `static inject = [...]` 声明依赖并在构造函数中通过 `ctx.inject` 获取连接/上下文后再注册 RPC 拦截。
- 对外暴露的标识符使用 branded type 工厂函数（如 `CordisDynamicPluginId`、`ApprovalRequestId`、`SessionId`）包裹字符串，避免裸字符串误用。
- 错误处理统一抛出带稳定 `code` 字段的专用 Error（如 `TypertGatewayError`、`RequestError.invalidParams`、`internalError`），由上层统一转换为 RPC envelope。
- RPC 方法通过 `@Remote('methodName')` 装饰器显式暴露，未装饰的方法仅进程内可见，形成明确的跨进程边界。
- 每个包遵循 `src/index.ts` 主入口 + `src/invariant.ts` 断言 + `tests/*.spec.ts` 测试的三件套结构，README 配套 README.md / README.zh.md / README.i18n.yaml 多语言文档。
- 跨进程传输前对参数与返回值执行 JSON 安全校验（`assertJsonValue` 递归检查非有限数、循环引用、symbol 键、稀疏数组等），确保 wire 数据可序列化。
