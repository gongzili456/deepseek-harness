- 配置对象使用 discriminated union（`transport: 'stdio' | 'streamable-http'`）并由 Schemastery/Zod 联合 schema 校验，默认值集中在 `RECONNECT_DEFAULTS` 常量中。
- 所有对外暴露的名称遵循 `mcp__<serverName>__<rawName>` 三段式命名，并通过纯函数 `publicToolName` 规范化至 DeepSeek 函数名契约，必要时追加 12 位 SHA-256 哈希避免碰撞。
- 资源生命周期通过 `ctx.effect` 注册清理回调（如 serverName 占用、connection dispose），确保插件卸载时自动释放。
- 异步状态机采用 generation 模式：每次连接创建新的 Client，并用 `isCurrent(generation)` 守卫防止竞态下的重复操作。
- 跨代际的 tool 同步通过单条 `syncChain` Promise 串行化，fetch 阶段失败保留上一代，swap 阶段注册冲突则回滚整代。
- 对不可信网络输入（MCP 返回的 content block、outputSchema）一律用 Zod schema 或 `assertSupportedJsonSchema` 进行边界校验后再消费。
