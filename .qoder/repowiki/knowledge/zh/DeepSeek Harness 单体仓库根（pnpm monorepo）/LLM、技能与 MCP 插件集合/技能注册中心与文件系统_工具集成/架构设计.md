模块以 `skill/` 为核心，定义 `SkillProvider`、`SkillRegistry`、`SkillCandidate`、`SkillDefinition`、`SkillInvocationPolicy` 等类型以及分层作用域（`ScopedLayers` + `SkillLayer`）的注册表；通过 Cordis `Service` 挂载到 `ctx.skills` 并派发 `skills/change` 事件。
- `skill/`：纯接口与注册表实现，负责合并 provider 目录、按 rank/providerOrder/localOrder 排序去重、缓存 catalog snapshot、校验候选/定义并渲染 `<skill_content>` 标记。
- `skill-filesystem/`：实现 `SkillProvider`，扫描 `.dsh/skills`、`.agents/skills`、自定义目录、用户目录及 `DSH_BUNDLED_SKILL_DIR`，解析 YAML frontmatter 与 Markdown 正文，使用 chokidar 监听根目录并在变更时调用 `invalidate()` 触发重新发现。
- `tool-skill/`：注册名为 `skill` 的工具，在 `agent/pre-step` 钩子中根据当前 agent 作用域快照生成持久化的 `<available_skills>` 目录消息，并拦截 `/name` 手势注入已加载技能的 instructions。
- `skill-badge/`：最小 bundled 提供者，直接返回一个静态候选并提供 assets 下的 dsh-badge.md 作为技能正文。
依赖方向单向：`skill-filesystem`、`tool-skill`、`skill-badge` 均只依赖 `@deepseek-ai/dsh-skill` 暴露的类型与常量，不反向引用彼此；所有插件通过 Cordis 的 `apply(ctx, config)` + `inject` 约定注册自身。
