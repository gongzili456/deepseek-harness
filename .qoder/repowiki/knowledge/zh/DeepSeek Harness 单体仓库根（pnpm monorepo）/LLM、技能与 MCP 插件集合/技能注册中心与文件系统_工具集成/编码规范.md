- 每个子包以 `apply(ctx, config)` 函数作为 Cordis 插件入口，并通过 `export const name` 与 `export const inject` 声明插件名与依赖服务。
- 对外暴露的配置对象同时以 `Schema` 形式用 schemastery 声明默认值与校验规则，供 Cordis 自动装配。
- 技能名称统一使用 kebab-case 正则 `SKILL_NAME` 校验，并通过 `isSkillName` 在注册、加载、工具参数多处复用。
- provider 通过 `registerProvider(create => ...)` 同步工厂注册，工厂内接收 `SkillProviderControl` 以感知 dispose 与手动失效。
- catalog 快照与收集结果通过 revision + cache key 缓存，变更时递增 revision 并清空缓存，再经 `skills/change` 事件通知消费者。
- 对不可信来源的文本输出统一通过 `escapeText` / `escapeAttr` 转义后再拼入 `<skill_content>`、`<available_skills>` 等 XML 风格标记。
