- 插件/服务通过 `static Config = z.object({...})` 声明 Schemastery 配置 schema，并在构造函数中以 `validateConfigKeys` 拒绝未知键，保证零配置或严格白名单。
- 对外暴露的测量结果通过 `structuredClone` + `deepFreeze` 返回深拷贝的不可变快照，避免共享可变状态。
- 通过 `declare module '@deepseek-ai/dsh-session/types' { interface SessionEventMap { ... } }` 扩展会话事件类型，将自定义事件（如 `llm/retry`、`llm/retry-started`）纳入类型系统。
- 使用 `WeakMap<Session, ReplayState>` 按会话隔离回放状态，并以 `consumedEvents` 游标顺序消费 `session.events`，确保回放幂等且可中断。
- 所有 Token 估算集中在 `estimate.ts` 的纯函数（`estimateContent`、`estimateHeader`、`estimateMessage`）中，通过常量 `CHARS_PER_TOKEN`、`BLOCK_OVERHEAD`、`ROLE_OVERHEAD` 统一启发式密度，供 meter 与 projection 共享。
- 异步等待统一封装为可取消形式：`cancellableDelay` 配合 `AbortSignal` 或在 `measure` 中使用 `AbortSignal.any([signal, lifetime.signal])`，确保插件销毁时能中止活跃重试。
