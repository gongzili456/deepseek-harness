本模块按职责拆分为三个并列的包族：llm/ 提供 provider 中立的运行时（适配器注册、消息组装、重试策略、Token 计量），llm-deepseek 与 llm-pi-ai 作为具体后端适配器实现，llm-retry 与 token-meter 作为横切拦截器通过事件回放注入调用链路；skill/ 提供技能发现与注册中枢，skill-filesystem、tool-skill、skill-badge 等扩展将本地文件、工具或徽章以 skill 协议暴露；mcp/mcp-client 则桥接外部 MCP 服务器，将其工具以 mcp__<serverName>__<rawName> 命名注册到 ctx.tools。三者共同依赖宿主框架的 Cordis 插件机制与 invariant 校验，由上层编排装配为完整的 Agent 能力集。
