- 插件通过导出 `name`、`inject = ['llm']` 和 `apply(ctx, config)` 函数注册为 Cordis 插件，并在 `apply` 中调用 `ctx.llm.registerAdapter` / `registerConfigurableProviders` 完成路由绑定。
- 配置使用 `@deepseek-ai/schemastery` 定义 `z.object` schema 并直接作为 `installSettingsSection` 的 schema 参数，使同一份 schema 同时承担运行时校验与 UI 生成。
- 连接事实（baseURL、apiKeyEnv、retryPolicy 等）封装为不可变对象并通过 per-operation thunk（如 `options()`、`profiles()`）读取，确保配置热更新对正在进行的流式请求不生效。
- API Key 通过 `credentialRef` 引用而非明文存储，由 `resolveApiKey` 钩子在请求时从 `ctx.credentials` 或 `launchEnvironmentOf` 解析，缺失时抛出带 `MISSING_CREDENTIAL` 代码的 `LlmError`。
- 路由/目录/注册表的变更通过 `deepEqualJson` 比较旧值与新值，仅在变化时调用 `registration.replace(...)` 或 `directory.replace(...)` 做原子替换，避免先销毁再注册的窗口期。
- HTTP 状态码统一映射为稳定的 `LlmError` 代码（AUTH、RATE_LIMIT、QUOTA_EXCEEDED、CONTEXT_WINDOW_EXCEEDED、SERVER 等），由适配器内部函数集中处理后再向上抛出。
