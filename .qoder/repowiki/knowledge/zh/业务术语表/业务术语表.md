### DeepSeek Harness
- 定义：由 DeepSeek AI 开发的开源 agent harness（dsh），采用「一切皆插件」的架构，基于 Cordis 运行时构建。当前处于 developer preview 阶段，API 可能包含破坏性变更。提供 CLI (`npx @deepseek-ai/dsh`)、Web UI 以及大量可插拔的 packages（llm、session、sandbox、tool、skill 等）。
- 别名：dsh、deepseek-harness

### Cordis
- 定义：DeepSeek Harness 所依赖的运行时框架，实现时空可组合性的编程范式；dsh 的所有能力（LLM 适配器、工具、技能、会话管理等）均以 Cordis 插件形式注册和编排。

### dsh-plugin
- 定义：社区插件生态的 discoverability 标签，发布到 GitHub 时添加该 topic 以便被 dsh 生态发现。
