`pnpm run test:snapshot:record` 调用真实 LLM API 录制会话日志到 `tests/snapshots`；`pnpm run test:snapshot:refresh` 用 replay 模式重写期望输出；`dsh web --patch examples/web-schedule/cordis.yml` 启用 Web 定时提醒 overlay；各示例通过 `DSH_SNAPSHOT=record|replay|refresh`、`DSH_PERMISSION_MODE=danger-full-access|workspace-write`、`DSH_SESSION_ROOT`、`DSH_CWD` 等环境变量切换行为。
