本模块是 workspace 根下的 umbrella，通过 `package.json` 以 `workspace:*` 依赖把各子包（`dsh-*`）暴露给 Node 解析，使每个子目录成为独立的可运行示例。

- 顶层按能力划分子目录：`acp-agent/`（Agent Client Protocol 自动化服务器）、`headless-agent/`（一次性无头 Agent）、`jsonrpc-agent/`（Python SDK + JSON-RPC 驱动）、`mcp-memory/`（MCP 内存服务器叠加）、`web-cordis/` 与 `web-schedule/`（Web 插件示例）。
- 每个示例自带 `cordis.yml` 声明式插件树（LLM、沙箱、工具、持久化、hook 等），并通过 `*.cordis.snapshot.yml` 覆盖件在快照模式下替换为 replay 后端；`DSH_SNAPSHOT`、`DSH_PERMISSION_MODE`、`DSH_CWD` 等环境变量控制行为分支。
- 测试组织遵循统一模式：`tests/fixtures/` 存放被测 agent 或子 agent 的 cordis.yml/driver，`tests/snapshots/<scenario>/` 存放 `input.json`、`session.jsonl`、`stdout.expected.jsonl`、可选 `system-prompt.expected.md` / `tool-schemas.expected.json` 等期望产物；`acp-agent/tests/acp.snapshot.ts` 使用 `@deepseek-ai/dsh-acp-snapshot` 的 `defineAcpSnapshotSuite` 集中声明场景表，`headless-agent/tests/harness.ts` 提供共享的 `codingHarness` 装配器。
- 依赖方向单向：示例 → `packages/*` 中的 dsh-* 插件；测试不反向依赖业务代码，仅通过 Cordis Context 与 JSONL 回放断言输出一致性。
