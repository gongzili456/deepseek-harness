- 每个校验/生成逻辑拆分为纯函数库（如 `package-invariants.ts`、`translation-pairing.ts`）与薄 CLI 包装（`verify-*.ts`），CLI 只负责解析根路径、调用核心函数并以 exit code 报告结果。
- Gate 通过 `pnpmScript` / `pnpmExec` 工厂构造，统一以 `{ id, label, displayCommand, command, args, needs?, env?, allowFailure? }` 描述，依赖关系在 `gatesForMode` 中集中声明而非硬编码顺序。
- 脚本入口使用 `if (process.argv[1] !== undefined && resolve(process.argv[1]) === scriptPath)` 判断是否直接执行，从而同一文件既可被 `run-gates` 作为子进程调用，也可单独运行。
- 路径规范化统一将 Windows 反斜杠替换为 `/`（如 `path.replaceAll('\\', '/')`），确保跨平台 glob 匹配与比较一致。
- 验证脚本通过收集 `violations` 数组并在末尾统一输出后 `process.exit(1)`，成功时打印计数信息，失败时 exit code 非零供 CI 判定。
- 测试文件与脚本同名并放在同级目录（如 `package-invariants.spec.ts`），使用 Vitest 并通过 `run-gates` 的 test 模式统一执行。
