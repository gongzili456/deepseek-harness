- 平台二进制通过 npm optionalDependencies + os/cpu 字段分发，JS 入口使用 `createRequire` 解析 `@deepseek-ai/node-addon-landlock-run-<platform>-<arch>/package.json` 定位二进制路径，而非环境变量或硬编码路径。
- 所有平台构建产物由 `scripts/build.ts` 统一驱动，依据各包 `prebuilds.json` 中的 `platform`/`binaries` 表生成目标，新增工具必须在 TOOLS 映射中显式声明，禁止隐式约定。
- CLI 契约（参数、退出码、输出格式）集中在 `docs/cli-contract.md` 并由 `LAUNCHER_FAILURE_EXIT = 125` 等常量在 JS 侧固化，消费者不自行拼接 launcher 参数，避免契约漂移。
- 发布前通过 `prepack` 钩子调用 `verify-entry-lib.mjs` 与 `verify-launcher-binary.mjs` 进行完整性校验，确保发布的 tarball 内容可被消费方正确安装。
- 测试区分环境能力：非 Linux 直接 exit 0 跳过，Landlock 不可用时根据 `NALR_REQUIRE_LANDLOCK` 决定是否失败，保证在非受限环境中仍可获得确定性结果。
