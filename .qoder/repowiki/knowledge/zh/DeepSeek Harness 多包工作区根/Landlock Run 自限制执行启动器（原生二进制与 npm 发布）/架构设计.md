模块以 `landlock-run/` 为独立 pnpm workspace，采用三包 npm 家族结构：
- `packages/entry`（`@deepseek-ai/node-addon-landlock-run`）：JS 入口，暴露 `launcherPath`、`grantArgs`、`probe` 三个导出，封装对预编译二进 CLI 契约（`docs/cli-contract.md`）的调用，通过 `createRequire` 解析当前宿主平台的可选依赖包。
- `packages/linux-x64` / `packages/linux-arm64`：仅包含 `bin/` 下的静态 musl 二进制与 `prebuilds.json`，通过 `os`/`cpu` 字段让 npm 安装时只拉取匹配架构的二进制。
- 顶层 `scripts/build.ts` 驱动构建：读取各平台包的 `prebuilds.json`，用本机 `musl-gcc -static` 编译 `packages/entry/src/main.c` 产出对应二进制；非 Linux 直接失败，强制 CI 多架构 runner 作为唯一可信构建源。
- 发布流程由 `scripts/{assemble-prebuilds,pack-release,publish-release,bump-release,commit-release}.mjs` 串联，配合 `verify-entry-lib.mjs`、`verify-launcher-binary.mjs`、`verify-packed-install.mjs`、`verify-release.mjs` 在 prepack/release 阶段做完整性校验。
- 测试位于 `test/`：`entry.test.js` 验证 JS API，`launcher.test.js` 针对真实内核做端到端行为测试（可通过 `NALR_REQUIRE_LANDLOCK=1` 强制要求 Landlock 可用）。依赖方向单向：entry → 平台二进制，脚本 → entry + 平台包，无反向依赖。
