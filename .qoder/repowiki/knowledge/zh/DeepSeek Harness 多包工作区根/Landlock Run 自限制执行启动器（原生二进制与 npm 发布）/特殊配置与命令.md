本地构建需 Linux + `musl-tools`（`apt-get install musl-tools`），运行 `pnpm build:native` 才会生成 `packages/*/bin/landlock-run`；测试默认跳过非 Linux 主机，若需强制要求 Landlock 可用则设置 `NALR_REQUIRE_LANDLOCK=1`。发布命令包括 `release:bump`、`release:commit`、`release:assemble-prebuilds`、`release:verify`、`release:pack`、`release:publish`、`release:verify-packed-install`。
