- 所有能力服务通过 `declare module '@deepseek-ai/cordis' { interface Context { ... } }` 向全局 Context 追加服务字段（`ctx.lsp`、`ctx.skills`、`ctx.compaction`）。
- 插件以命名导出 `name`、`inject`、`Config` schema 与 `apply(ctx, config)` 形式暴露，并在 `apply` 内完成资源注册与 effect-scoped 清理。
- 对外错误统一继承自基础 Error/HarnessError 并携带稳定的 `code` 字符串（如 `LSP_CONFLICT`、`LSP_INVALID_PROVIDER`、`ManualCompactionError.code`），调用方按 code 分支处理而非解析 message。
- 配置校验集中在顶层 `z.object({...}).default(...)` schema 中声明，并在构造函数或 `validate*` 辅助函数中对正整数、timer 上限等做 fail-fast 断言。
- 异步工作普遍接受 `AbortSignal`，并通过 `AbortSignal.any([signal, this.lifetime.signal])` 将调用取消与提供者自身销毁信号合并传播。
- Provider/Engine 类内部使用 WeakMap/WeakSet 或版本号（revision）配合缓存键来保证作用域隔离与失效一致性，避免内存泄漏。
