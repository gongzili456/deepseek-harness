- 每个包以 `apply(ctx, config)` 作为插件入口，并通过顶层 `export const name` 与 `export const inject = [...]` 声明插件名与服务依赖。
- 配置对象同时导出 TypeScript interface 与同名 schemastery schema（`z.object({...})`），用于运行时校验与类型推导。
- Session 投影通过 `ctx.inject(['sessionProjections'], ...)` 条件注册，使无 projection 组件的 headless 组装不受影响。
- 每个包附带 `src/invariant.ts` 并在 tests 下对应 `invariant.spec.ts` 中用 `expectInvariant` 断言领域不变式。
- 对外类型通过 `export type * from './types.ts'` 从 package root 重新导出，保证聚合程序消费 `.d.ts` 时仍能拿到 SessionProjectionMap 合并。
- 错误统一抛出带稳定 code 的错误类（如 GoalError、PresetMountError），便于调用方按 code 分支处理而非字符串匹配。
