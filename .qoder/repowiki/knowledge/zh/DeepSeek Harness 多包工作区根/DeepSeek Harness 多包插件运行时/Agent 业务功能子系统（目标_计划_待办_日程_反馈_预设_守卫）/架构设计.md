本模块由多个独立 npm 包组成，每个包围绕一个 Agent 能力以 Cordis 函数插件形式暴露 `apply(ctx, config)` 入口，并通过 `name`/`inject` 元数据声明依赖的服务。
- goal/：核心领域包 `goal/` 实现事件溯源的 GoalService（基于 TypertRemoteService），通过 `ctx.goals` 注入；`goal-round-driver/` 消费该服务驱动同会话续跑；`tool-goal/` 注册模型可见工具；`command-goal/` 注册人类命令，形成“领域 → 驱动 → 工具/命令”的分层。
- schedule/schedule/：基于 Session 持久化变更流 `schedule/change` 的纯折叠域 + `ScheduleRuntime` 按根 Agent 生命周期挂载定时器与工具，遵循 AGENTS.md 中“仅对加载后发布的根 Agent 生效、fork 不继承父提醒”的规则。
- feedback/：`command-feedback/` 注册 `/feedback` 命令并追加 `feedback/record` 日志事件；`message-feedback/` 提供消息级反馈适配器，两者互不依赖。
- todo/tool-todo/：通过 `defineTool` 注册 `todo_write`，可选地通过 `sessionProjections` 注册 `todos` 投影单元，实现 last-write-wins 的全量列表替换。
- plan/plan-mode/：以 `PlanModeService` 暴露计划模式 API，结构与 goal 类似但面向规划阶段。
- preset/agent-presets/：最复杂的装配层，`AgentPresets` Service 负责从系统/用户目录发现 `cordis.yml` 组合文件，维护 per-preset 的 standing mount（按文件 mtime+size 戳管理代际），通过 dsh-scope 的 `bindScopeParent` 将 Agent scope 挂到 mount 上，支持 `mount/composeFrom/recompose` 以及冷读场景的 `standingKeyFor`。
- guard/*：轻量守卫插件（repeat-tool-reminder、timeout-policy）监听 `tools/post-execute` / `agent/pre-step` 等钩子，向下游决策链注入上下文或阻断，不持有持久状态。
所有包共享约定：每个包自带 `invariant.ts` 在测试中校验不变式；配置使用 schemastery (`z.object(...)`) 声明；类型通过 `export type * from './types.ts'` 保持聚合程序能收到 SessionProjectionMap 合并。
