- Cordis 插件以 `name`、`inject`、`apply(ctx)` 三件套形式导出，并通过 `package.json` 的 `exports` 字段分别暴露 `.` 与 `./invariant` 入口。
- 在拦截器中优先判断上下文条件（如 `sessionId` 是否存在、`exec.parent` 是否为顶层）后直接 `next()` 透传，避免不必要的 checkpoint 开销。
- 持久化失败采用 fail-closed 模式：在 `llm/stream` 中直接抛出异常阻止 adapter 调用，在 `tools/execute` 中将错误包装为 `ToolExecutionResult` 且不调用工具体。
- 测试通过自定义 `SessionPersistence` 与 `LlmAdapter` 模拟 I/O，并使用 `Promise.withResolvers` 在 `session/flush` 上设置 gate 来精确断言 flush 与下游执行的先后顺序。
