本模块由两个并列的 Cordis 插件组成：
- `tool-session-query`（服务端）：以 `apply(ctx, config)` 为入口，在 `index.ts` 中通过 `defineTool` 注册五个模型工具（`session_search`、`session_event_search`、`session_trace`、`session_event_trace`、`session_event_read`），并通过 `ctx.systemPrompt.section` 注入统一提示。参数校验集中在 `input.ts`，业务编排集中在 `operations.ts`，调用 `ctx.sessionQuery` 服务前经 `service-boundary.ts` 做错误白名单映射（将 `SessionQueryError` 翻译为安全的 `HarnessError`），并通过 `workspace-access.ts` 基于调用者 session 的 `cwd` 进行工作区级授权过滤（authorizeTarget / authorizeSessionIds / authorizeDescendants）。分页聚合由内部 `collectPages` 完成，支持 cursor 去重与超时中止。
- `session-log-export`（Web 客户端）：`src/index.ts` 注册 `/export` 命令；`src/client/index.ts` 作为浏览器插件注入 `sessionLogDownload` 控制器、本地化字典，并监听 `command/executed` 事件触发下载；`controller.ts` 维护每个 Session 的下载状态（`SnapshotStore`），通过 HEAD 探测 `/api/session.export?sessionId=...&includeDescendants=true` 后调用浏览器 `<a download>` 下载 ZIP；`Dialog.tsx`、`HeaderAction.tsx` 通过 `slots.inject('conversation.session.header.utilities')` 挂载到会话头部。
依赖方向：`operations → service-boundary + workspace-access → @deepseek-ai/dsh-session-query`；客户端插件仅依赖 `@deepseek-ai/dsh-client-*` 运行时与 slots 系统，不直接访问服务端。
