- 插件通过导出 `name`、`inject` 数组和 `apply(ctx, ...)` 函数暴露给 Cordis 加载器，服务端插件额外导出 `Config` 的 schemastery schema。
- 所有对 `ctx.sessionQuery` 的远程调用都包裹在 `serviceBoundary.call` 中，以便集中捕获异常并映射为安全的 `SESSION_QUERY_*` 错误码。
- 工作区授权统一通过 `workspace-access` 模块完成：目标 session 必须与调用者共享 `cwd`，祖先/后代 lineage 按 `recordAuthorized` 规则投影，未授权路径被截断或替换为 `null`。
- 工具参数校验集中在 `input.ts`，使用 `assertNonNegativeSafeInteger`、`buildEventFilters`、`buildSessionFilters` 等纯函数构造过滤器，避免在操作函数内散落校验逻辑。
- 客户端状态通过 `createSnapshotStore` 发布不可变快照，UI 组件（Dialog/HeaderAction）仅消费只读 state，控制器负责更新。
- 下载流程先执行 HEAD 请求验证可下载性，再复用同一 URL 发起真实下载，并以 `sessionLogZipFilename` 规范化文件名，防止非法字符污染。
