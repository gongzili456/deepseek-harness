本模块以 `core/session` 的内存会话为唯一事实源，通过 Cordis 上下文键将多个独立包装配成完整的数据平面：
- 写入侧：`session-persistence` 定义 `ctx.sessionPersistence` 抽象，由 `session-persistence-jsonl` 与 `session-persistence-sqlite` 作为首方存储后端注册；`session-checkpoint-policy` 在模型请求、工具副作用、Agent 步骤边界前调用该抽象做语义检查点。
- 读侧投影：`session-projection` 提供 `ctx.sessionProjections` 驱动纯函数式投影单元，`session-projection-cache` 负责检查点读写，`session-stats` 作为内置统计投影注册到同一框架。
- 标题：`session-title` 维护标题状态并注册 LLM 提供者（`session-title-first-prompt-llm` / `session-title-all-prompts-llm`），回退到确定性策略。
- 遥测：`session-telemetry` 捕获、脱敏并投影会话活动，`session-telemetry-otel` 作为 OTLP 后端实现。
- 查询（独立 sibling 组）：`session-query` 定义可信读取与关系查询，`session-query-sqlite` 基于 FTS5 实现索引，`tool-session-query` 暴露给模型，`session-log-export` 提供 Web 端 ZIP 导出。
所有子包共享统一的 `invariant.ts` 运行时校验约定，并通过 Cordis 上下文键（`ctx.sessionPersistence`、`ctx.sessionProjections`、`ctx.sessionTitle`、`ctx.sessionQuery`、`ctx.tools` 等）完成解耦装配，部署时仅选择一种 title provider 与一种 telemetry backend。
