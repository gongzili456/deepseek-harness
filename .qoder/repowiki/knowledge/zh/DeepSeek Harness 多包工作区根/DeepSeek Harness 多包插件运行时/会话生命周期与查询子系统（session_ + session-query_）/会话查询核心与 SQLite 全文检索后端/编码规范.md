- 对外错误统一通过 `SessionQueryError` 抛出，并附带固定字符串错误码（如 `SESSION_QUERY_INVALID_CONFIG`、`SESSION_QUERY_INDEX_FAILED`、`SESSION_QUERY_STALE_CURSOR`），便于上层分类处理。
- 所有返回给调用方的 session header、events、surface 等数据都通过 `structuredClone` 深拷贝后再返回，保证一次 corpus 观察的一致性隔离。
- 搜索请求先经 `normalizeSessionRequest`/`normalizeEventRequest` 归一化（默认 limit、空数组兜底、游标解析），再由 `buildSessionWhere`/`buildEventWhere` 编译为参数化 SQL 片段，避免直接拼接用户输入。
- 对 SQLite 能力边界进行显式断言：`assertPortableBindingCount` 限制绑定数不超过 32766，`assertFts5OuterPredicateCount` 限制外置谓词不超过 14，超限即抛 `SESSION_QUERY_INVALID_FILTER`。
- 分页游标采用 base64url 编码的 JSON payload（含 version、instance、scope、fingerprint、generation、offset），解码时校验 instance/scope/fingerprint/generation 匹配，否则报 `SESSION_QUERY_INVALID_CURSOR` 或 `SESSION_QUERY_STALE_CURSOR`。
- 持久化与实时源通过 `_observeStable` 重试最多两次直至 `persistence.listSnapshots` 与 live session 集合稳定，再用 generation/fingerprint 增量更新索引，避免竞态导致的重复工作。
