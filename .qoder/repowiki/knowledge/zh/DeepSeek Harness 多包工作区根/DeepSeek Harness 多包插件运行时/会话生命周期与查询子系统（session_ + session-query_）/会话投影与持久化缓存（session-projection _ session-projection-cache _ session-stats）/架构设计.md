本模块由三个相互协作的包构成，遵循“领域插件贡献纯数学、框架负责订阅与一致性”的三层边界：
- `session-projection`（核心 seam）：定义 `ProjectionDefinition<K,S>`（init/apply/view/stateVersion）、`SessionProjectionRegistry`（Cordis Service，挂载为 `ctx.sessionProjections`），通过监听 `session/event` 对每个已注册单位进行 eager drive；使用 `WeakMap<Session, UnitCell>` 维护 per-session 的水位缓存，支持 snapshot/checkpoint/viewCheckpoint/restore/restoreFloor 等冷读路径，并通过 schema.parse 保证 view 输出类型安全。
- `session-projection-cache`（持久化层）：依赖 storage-domain 打开 `session_projcache` 表，以 write-behind 模式在 turn/end、session/disposed 两个强制落盘点之外按 `writeEveryEvents`/`writeIntervalMs` 节流写入；提供 cachedSnapshot（零 I/O listing 视图）和 coldSnapshot（缓存行 + persistence readFrom 尾追回放 + registry.restore 重折叠 + fail-soft 回写）两条冷读路径，并用 `createdAt/cwd` 构成的 identity 校验记录归属。
- `session-stats`（领域投影插件）：仅暴露 Cordis plugin（`name='session-stats'`，`inject=['sessionProjections']`，`apply` 中调用 `register(sessionStatsProjectionDefinition)`），其 `projection.ts` 将 step/start→assistant/message/tool call/result 等事件折叠为 turns/steps/llmMs/toolMs/ttftMs/decodeMs 等总量，stateVersion=1 用于版本兼容。
依赖方向单向：`session-stats` → `session-projection` ← `session-projection-cache`（后者通过 type-only import 注入 `ctx.sessionPersistence`），三者均通过 Cordis Context 扩展名（`ctx.sessionProjections`、`ctx.sessionProjectionCache`）解耦。
