模块由四个相互协作的子包组成：`session-title` 是核心服务包，导出 `SessionTitleService`（继承自 Cordis `Service`），通过监听 `session/event`（`user/message`、`request/header`）和全局 `llm/stream` 钩子编排标题生命周期；它维护每个 session 的工作状态（revision/pending/active/fallback），实现自动去重、supersede 取消、AbortSignal 组合与服务级 drain。`session-title-llm` 是共享基础设施，提供 `registerSessionTitleLlmProvider`、`generateSessionTitleWithLlm`、配置校验与系统提示模板，所有 LLM 驱动提供者都复用此层。`session-title-first-prompt-llm` 与 `session-title-all-prompts-llm` 是两个薄插件，仅通过不同的 `selectMessages` 选择器（取第一条 vs 全部人类消息）注册到核心服务，分别对应 `first-prompt` 与 `all-prompts` 两种自动触发模式。类型层面，`types.ts` 单独声明 `SessionProjectionMap.title` 投影键，避免值依赖污染纯类型入口；服务还向 `@deepseek-ai/dsh-session/types` 扩展 `session/title` 与 `session/title-llm-request` 两个 log-only 事件。依赖方向严格单向：first/all → llm → core，core 不反向依赖任何 LLM 实现。
