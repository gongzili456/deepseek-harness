本模块由两类子包构成统一的运行时骨架：
- `packages/core/*` 基于 Cordis 的 `Context`/`Service` 体系，按职责拆分为 agent_core（Agent 注册与生命周期）、agent_loop（ReactLoopAgent 驱动循环）、runtime_primitives（scope 作用域、session 事件溯源、system-prompt 系统提示、tools 工具注册与执行流水线）以及 agent-default-model、agent-tool-presentation 等扩展点。
- `packages/typert` 提供 generator/loader/protocol/registry，实现 TypeScript 源码分析到 host/client 代码生成、运行时注册中心与自动发现。

跨子包的编排契约集中在启动期：`agent-loop` 作为 Cordis Service 注入 `['agents','sessions','llm','tools','systemPrompt']`，在构造时把自身设为 `ctx.agents` 工厂、向 `ctx.systemPrompt` 注入 provider/model/cwd 变量，并通过 `SessionPreparation` 协调 `session` 包的持久化恢复；`session` 在 `SessionStore` 构造中通过 `ctx.inject(['typert'], ...)` 将 `Session` 对象注册到 `TypertLookupMap.session`，使 session 成为可被远程调用的 typert 对象；`tools` 通过 `ctx.systemPrompt.tools(...)` 暴露 schema，供 agent_loop 在 LLM 调用前组装工具列表。所有子包共享同一套约定：以 `declare module '@deepseek-ai/cordis'` 扩展 Context/Events，用 `@deepseek-ai/schemastery` 声明配置校验，通过 scoped events 进行跨作用域通信，并以 `invariant.ts` 统一断言入口。
