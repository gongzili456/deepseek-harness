- 对外暴露的公共 API 集中在各包 `src/index.ts`，并通过 `export * from './xxx.ts'` 重新导出子模块的类型与函数，保持单一入口。
- 通过 `declare module '@deepseek-ai/cordis'` 扩展 `Context` 接口（如 `sessions`、`systemPrompt`、`tools`）并在 `Events` 分支中以 JSDoc 标注 `@mode emit/waterfall/parallel` 声明事件语义。
- 所有跨边界的数据（事件 data、prompt 变量、tool 输出、session header）在进入持久化或派生视图前统一调用 `snapshotJsonValue` 深拷贝并 `deepFreeze`，确保不可变与 JSON 可序列化。
- 注册表采用 `ScopedLayers` + `NamedEntries`/`AnonymousEntries` 的模式：全局层与作用域层叠加，同名注册在作用域内被 shadow，重复注册抛出含作用域信息的错误。
- 事件分发统一通过 `scopeTarget(base, scopeOf(ctx))` 包裹后再调用 `ctx.events.dispatch`/`ctx.waterfall`，使 agent-scoped 监听器仅收到其作用域及后代的作用域事件。
- 服务类继承自 `Service` 并在构造函数中通过 `static Config: z<...>` 声明配置 schema，同时通过 `ctx.inject([...], ...)` 注入依赖（如 `typert`、`systemPrompt`）。
