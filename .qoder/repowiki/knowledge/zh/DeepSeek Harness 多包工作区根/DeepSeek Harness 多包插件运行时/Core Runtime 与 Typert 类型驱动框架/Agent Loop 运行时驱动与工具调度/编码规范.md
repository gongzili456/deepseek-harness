- 通过 `AbortSignal` 串联 caller 取消、owner fiber 卸载与 factory teardown 三个生命周期，所有异步边界在 await 前检查 `signal.throwIfAborted()` 或 `raceAbort`。
- 对 session 的持久化写入统一使用 `session.append('event/type', data, { surfaceOp: 'append' })` 形式，并以 `sourceEventSeqs` 关联前后事件以支持回放。
- 对外暴露的配置项使用 `z.object(...).default(...)` 声明 schema，并在构造函数中通过 `installSettingsSection` 挂载到 `dsh-settings`，运行时通过 getter 读取最新值。
- 长生命周期对象（如 PreparedAgent 的反向 teardown）采用 memoized Promise 模式，确保多次调用共享同一份资源释放逻辑。
- 工具执行结果按模型顺序提交：使用 `committed` 指针配合 `commitReady` 协程，只有连续已完成的 slot 才会写入 session，保证 order-preserving 的 tool/result 序列。
- 通过 `ctx.on('session/event')` 订阅权威事件来维护轻量投影状态（如 RuntimeContextProjection），而非持有可变缓存。
