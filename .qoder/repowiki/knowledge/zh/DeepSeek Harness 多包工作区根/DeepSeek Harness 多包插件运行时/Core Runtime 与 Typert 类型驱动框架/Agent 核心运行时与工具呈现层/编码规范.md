- 通过 `declare module '@deepseek-ai/cordis' { interface Context { ... } }` 与 `interface Events { ... }` 在类型层面扩展 Cordis 上下文与事件契约，而非使用字符串键。
- 插件以 `Service` 子类或 `apply(ctx, config)` 函数形式挂载，并使用 `ctx.effect` / `ctx.inject` 管理副作用与依赖注入的生命周期。
- 对外暴露的配置对象统一用 `schemastery` 的 `z.object({...})` 定义 schema，并在 `package.json` 中以 peerDependency 声明运行时依赖。
- Agent 相关事件通过 `agentEvents(ctx, agent).emit/serial/waterfall` 分发，且 payload 中的 `agent` 字段由调度器注入，调用方只传剩余字段，保证 subject 与 scope key 一致。
- 异步边界使用 `AsyncLocalStorage` 配合显式状态机（如 `initiatorState: 'active'|'closing'|'disposed'`）控制可进入性，并在 dispose 时禁用存储以避免悬挂引用。
- 错误与不变量集中放在同目录的 `invariant.ts` 中，通过命名常量（如 `NO_FACTORY_MESSAGE`）抛出语义化错误信息。
