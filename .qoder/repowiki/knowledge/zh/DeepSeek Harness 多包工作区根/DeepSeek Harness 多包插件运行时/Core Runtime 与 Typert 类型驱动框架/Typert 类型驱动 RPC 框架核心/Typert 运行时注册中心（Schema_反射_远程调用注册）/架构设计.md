模块以 `service.ts` 中的 `TypertRegistry` 类为核心，继承自 Cordis 的 `Service`，通过四个内部 Store 实现关注点分离：`DescriptorStore` 管理本地与远程的 `InvocationDescriptor`（endpoint/id 去重、变更事件）、`RemoteStore` 包装远程包的注册生命周期、`LookupStore` 维护 Host 对象查找 Provider/Resolver 对、`ContextStore` 管理 Host Context Provider 与 Client Context Binder；所有 Store 共享 `ChangeSource` 并通过 Cordis `Context.effect` 保证注册/注销的原子性与自动清理。`types.ts` 定义纯类型契约（`TypertContribution`、`TypertPackageModel`、`TypertSchemaRecord` 等），`index.ts` 作为宿主入口并扩展 `@deepseek-ai/dsh-typert-protocol` 的 `TypertRegistryContract` 接口，暴露 `register/get/resolve/list/getPackage/listPackages/toJSONSchema` 以及 `local/remotes/lookups/contexts` 子视图；`client/index.ts` 提供浏览器端安装器 `apply(ctx)`，复用同一实现；`invariant.ts` 作为空实现的 invariant 插件向 `dsh-invariants` 服务声明包所有权。依赖方向单向：本模块依赖 `@deepseek-ai/dsh-typert-protocol`（协议类型）和 `zod`（Schema 运行），被上层 Host/Client 通过 Cordis 注入使用。
