- 对外暴露的标识符（service key、namespace、export name、scope key）统一通过 `validateName` 调用 `isTypertRemoteSegment` 进行字符集校验，非法值抛出带 `typert-protocol:` 前缀的 TypeError。
- 装饰器元数据保存在模块级 `WeakMap<object, Map<string, StoredRemoteMarker>>` 中，按 prototype 隔离，并通过 `Object.freeze` 固化每个 marker 与 invocation 标记，禁止外部修改。
- 所有 Registry 接口（Local/Remote/Lookup/Context）均提供 `register`/`configure`/`get`/`list`/`subscribe` 五件套，并以返回 `TypertDisposer` 的方式支持作用域内撤销。
- 类型层面使用 `unique symbol`（`LOOKUP_HOST`、`LOOKUP_WIRE`、`CONTEXT_WIRE`）在编译期区分 Host/Wire 两端的关联，配套提供 `TypertLookupHost`、`TypertLookupWire`、`TypertContextWire` 等提取类型。
- 错误类型采用具名 Error 子类（如 `TypertLookupFailure`）并在构造函数中固定 `this.name`，以便上层区分业务拒绝与基础设施故障。
