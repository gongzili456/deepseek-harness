模块以 `src/types.ts` 为单一契约层，定义所有跨进程边界共享的类型（`InvocationDescriptor`、`TypertLookup`、`TypertContext`、`TypertClientRemote`、四大 Registry 接口等），并通过 `declare module '@deepseek-ai/cordis'` 将 `typert: TypertRegistryContract` 扩展到 Cordis 的 `Context`。

`src/index.ts` 暴露运行时 API：
- `bindTypertRemote` / `TypertRemoteService` 将 Cordis Service 冻结为可被 Gateway 发现的 `TypertGatewayBinding`；
- `@Remote` 与 `@RemoteScope` 方法装饰器通过 ES Class Decorator `addInitializer` 把调用模式写入模块级 `WeakMap<prototype, Map>` 私有表，由 `remoteMethods()` 读取快照；
- `isTypertRemoteSegment` + `validateName` 用正则校验命名段，保证能安全穿越共享 RPC 载体。

`src/invariant.ts` 作为 Cordis 插件（`name = 'typert-protocol-invariant'`，`inject = ['invariants']`）注册空安装函数，声明该包无运行时不变量需要断言。

依赖方向单向：index → types；invariant 仅依赖 types 中的 Context 类型；对外不暴露内部 WeakMap，仅通过只读快照与冻结对象形成稳定边界。`package.json` 通过 `exports` 字段分别导出 `.`、`./types`、`./invariant` 三个入口，并保留 `./src/*` 供源码引用。
