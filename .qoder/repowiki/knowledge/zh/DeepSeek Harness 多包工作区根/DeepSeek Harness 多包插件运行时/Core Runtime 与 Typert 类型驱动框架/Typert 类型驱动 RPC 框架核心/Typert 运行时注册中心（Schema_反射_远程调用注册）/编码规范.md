- 所有可变状态均通过 `ctx.effect` 返回 disposer 来管理生命周期，确保重复注册在同一作用域内被拒绝并在 dispose 时自动回滚。
- 对外暴露的 Store 通过 `view(ctx)` 方法在每次访问时绑定当前 `Context`，使订阅者随上下文自动解绑。
- 键空间采用 `<package>#<name>` 形式的稳定全局标识，由 `typertKey` / `typertPackageKey` / `typertEndpoint` 三个工厂函数统一生成，禁止直接拼接字符串。
- 所有外部输入（包名、schema name、lookup key、wire field、namespace/method 等）在进入存储前经由 `validateSegment` / `validateWireName` / `validateNonempty` / `validateCodec` 等校验函数集中验证，失败抛出带 `typert:` 前缀的错误消息。
- 变更通知通过统一的 `ChangeSource` 派发 `TypertRegistryChange`（含 `kind` 与 `key`），各 Store 在 commit/register/configure 后 emit，并在 dispose 中 emit 移除事件。
- 类型与实现分离：`types.ts` 仅声明纯类型与数据结构，`service.ts` 负责全部运行时逻辑，`client/index.ts` 仅提供薄包装安装器，避免循环依赖。
