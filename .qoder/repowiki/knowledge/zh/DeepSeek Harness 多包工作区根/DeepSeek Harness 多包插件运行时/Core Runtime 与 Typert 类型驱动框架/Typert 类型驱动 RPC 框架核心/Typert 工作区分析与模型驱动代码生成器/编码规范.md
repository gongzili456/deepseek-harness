- 所有错误通过具名 Error 子类抛出（`TypertAnalysisError`、`TypertEmitError`），并在消息前缀标注来源如 `typert(...)` 或 `typert Zod emitter:`。
- 分析器与发射器之间通过纯数据模型（FaceModel / TypeGraph / PackageModel）解耦，禁止直接传递 TS 语法节点或 Program。
- 生成的 JS/DTS 文件首行统一添加 `/* Generated by @deepseek-ai/dsh-typert-generator from ... — do not edit. */` 注释。
- 字符串字面量通过内部 `quote()` 函数转义单引号、反斜杠与换行后再嵌入模板，避免手动拼接导致的转义遗漏。
- 工作区级缓存通过 `WorkspaceCaches` 共享已解析的 tsconfig、CompilerHost 与源文件，write 模式通过 `invalidate(file)` 使编辑后的文件失效并重跑一次 check-mode 分析。
- 批量分析采用 `analyzeInBatches(batchSize)` 将 packages 切分后合并 `mergeWorkspaceModels`，默认 batch size 为 8。
