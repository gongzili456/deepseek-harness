模块按「分析 → 模型 → 渲染/发射」三层组织，依赖方向单向：`analyzer.ts` 使用 `typescript` API 解析 tsconfig 聚合、构建 Program 并抽取为 `model.ts` 中定义的 FaceModel/TypeGraph；`emitter.ts` 仅消费 FaceModel 与 TypeGraph，通过 `renderer.ts` 将类型节点渲染为字符串，再拼接出 `typert.{face}.js`、`typert.{face}.d.ts` 以及 host 面的 `typert.remote-client.*`；`workspace.ts` 的 `WorkspaceTypertGenerator` 组合 analyzer 与 emitter 完成 discover→analyze→emit 流水线，并在 emit 后校验 package.json 的 exports/files 字段；`tsdown-plugin.ts` 作为 rolldown/tsdown 插件入口，在 transform 阶段用 `ts.transpileModule` 降级装饰器，在 writeBundle 阶段调用 WorkspaceTypertGenerator 输出产物。`cordis-catalog.ts`、`invariant.ts` 提供 Cordis 服务目录与断言辅助。测试位于 `tests/`，包含 fixture workspace 与 snapshot 验证。
