- 所有对外错误信息统一以 `typert-loader: ${pkgName} ...` 前缀开头，便于在多包注册失败时快速定位缺陷来源。
- manifest 字段校验采用一组小型 `require*` 辅助函数（requireObject/requireArray/requireString/requireDocumentation/requireMembers/requireTypes/requireInvocation/requireStrictCodec），每个函数只负责一种类型约束并在不满足时抛出带上下文的 Error。
- 包级资源（artifact 路径、已导入 manifest）通过 Map 按包名缓存且永不失效，确保同一进程内每个包只被解析/导入一次。
- 增量同步采用 dirty set + queueMicrotask 模式：事件回调仅入队 entry name，microtask 中一次性 flush 并消费队列，避免重复调度。
- 异步任务通过 pending/registered 双 Map 区分“正在加载”和“已注册”，并在 finally 分支清理 pending，防止并发 import 导致重复注册。
- Config 使用 schemastery 的 z.object(...) 定义并附带默认值，同时导出同名 TypeScript interface 与运行时 schema 供调用方验证。
