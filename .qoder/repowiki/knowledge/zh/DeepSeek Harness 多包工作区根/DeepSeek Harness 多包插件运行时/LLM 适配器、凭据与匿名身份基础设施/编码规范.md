- 所有服务类继承 cordis 的 Service 并在构造函数中调用 super(ctx, 'serviceName')，同时通过 declare module '@deepseek-ai/cordis' 向 Context 接口注入属性（如 ctx.llm、ctx.credentials、ctx.tokenMeter）。
- 对外暴露的公共类型集中在 types.ts 并通过 package.json 的 exports 单独导出 './types'，而实现细节留在 src/ 下不暴露给消费者。
- 配置对象使用 schemastery 的 z.object(...) 声明并作为 settings section 的 schema，再通过 installSettingsSection 挂载到 ctx.settings，变更时通过 onChange 触发原子化的 registration.replace() 或 directory.replace()。
- API Key 一律以 CredentialRef（POSIX 环境变量名）形式传递，在请求边界通过 credentials.resolve(ref) 或 launchEnvironmentOf 解析，并使用 assertUsableApiKey 进行空白/非法字符校验，禁止将密钥字面量写入日志或 UI。
- 错误统一通过 LlmError（或 HarnessError）抛出，并附带稳定 code 字符串（如 INVALID_CREDENTIAL、NO_ADAPTER、DUPLICATE_ADAPTER），便于上层分类处理。
- 对并发安全的注册/目录更新采用「先全量校验再一次性 commit」模式：prepareRoutes/directoryEntries 构造候选集，commitRoutes/ensureRegistrationFacts 才执行 Map 替换并触发 emitAdaptersUpdated 事件。
