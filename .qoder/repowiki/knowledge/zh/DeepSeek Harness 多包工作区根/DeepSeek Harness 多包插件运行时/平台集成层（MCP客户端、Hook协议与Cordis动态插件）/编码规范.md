- 每个子包遵循统一的导出结构：主入口 `lib/index.js`、类型声明 `lib/types/index.d.ts`、独立 `./invariant` 子路径，并在 `package.json` 的 `exports` 中显式声明。
- Cordis 插件统一以 `export const name`、`export const inject = [...]` 声明插件名与依赖服务，并以 `export function apply(ctx, config)` 作为生命周期入口。
- 配置对象一律通过 `@deepseek-ai/schemastery`（`z.object`/`z.union`）定义并附带默认值，使配置在加载时即完成校验与归一化。
- Host/Client 跨进程方法统一用 `@Remote('methodName')` 装饰器暴露，并在方法内对 stale run/pluginId 做幂等校验后返回结构化 `{ok, reason, message}` 响应。
- 错误与诊断信息集中通过 `invariant.ts` 提供的断言函数抛出，避免裸 `throw new Error` 散落各处。
- 测试文件与源码一一对应放置于各包的 `tests/` 目录，使用 `.spec.ts` 后缀并按被测模块拆分（如 `codec.spec.ts`、`runner.spec.ts`）。
