- 每个能力家族通过扩展 Cordis 的 `Context` 接口声明上下文键（`ctx.subagents`、`ctx.workflowEngine`、`ctx.jobs`），并在同文件顶部用 JSDoc 注释说明该 service 的职责与边界。
- 契约包以抽象类（`SubagentRuntime`、`WorkflowEngine`、`JobRegistry`）暴露服务定义，具体实现作为独立 npm 包注册到同一上下文键，避免耦合。
- 生命周期事件通过 `declare module '@deepseek-ai/cordis' { interface Events { ... } }` 集中声明，并使用 `@mode emit` 标注为纯发射事件。
- 错误采用带机器可读 `code` 的专用 Error 子类（`SubagentError`、`WorkflowError`、`HarnessError` 派生），区分致命与非致命路径以便组合器决策。
- 作用域与权限通过调用方传入的 `Agent`/`Scoped` 载体进行围栏校验，所有列表、读取、取消操作均以 caller 身份检查 owner 归属。
- 每个子包目录结构统一包含 `src/`、`tests/`、`README.md`、`README.zh.md`、`README.i18n.yaml`、`package.json`、`tsconfig.json`，且测试文件与源码一一对应。
