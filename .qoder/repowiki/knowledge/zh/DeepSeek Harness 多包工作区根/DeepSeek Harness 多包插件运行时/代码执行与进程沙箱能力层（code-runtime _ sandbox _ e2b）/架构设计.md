本模块按能力域划分为三个并列的 package 族，每个族都遵循「抽象服务定义 + 平台实现」的分层模式：
- code-runtime：`@deepseek-ai/dsh-code-runtime` 定义 `CodeRuntime` 抽象类、共享保留字/全局名集合（`PORTABLE_RESERVED_WORDS`、`RESERVED_BINDING_GLOBALS`、`DUNDER_MEMBER`），`@deepseek-ai/dsh-code-runtime-worker-thread` 基于 Node `worker_threads` 实现 TypeScript 程序隔离执行，通过消息端口以结构化 JSON 协议与 worker 通信，并维护 computeMs 忙时预算、maxWallMs 墙钟上限与 maxOutputBytes 输出限额。
- sandbox：`@deepseek-ai/dsh-sandbox` 定义 `SandboxProvider` 抽象、`SandboxMode`（read-only/workspace-write/danger-full-access）、`ConfinedArgv` 及拒绝签名约定；`@deepseek-ai/dsh-sandbox-local` 按平台链选择 bwrap → landlock（Linux）、seatbelt（macOS）、windows-acl（win32），通过功能探测仲裁候选者并缓存结果；`@deepseek-ai/dsh-sandbox-windows-acl` 使用 koffi FFI 调用 Win32 API 创建受限 token 与 ACL 写允许列表；`@deepseek-ai/dsh-sandbox-policy` 提供 per-call 策略解析与 session/workspace root。
- e2b：`@deepseek-ai/dsh-e2b` 封装 `e2b` SDK 生命周期（创建、cwd 初始化、超时 kill、dispose 清理），`@deepseek-ai/dsh-subprocess-e2b` 和 `fs-e2b` 分别实现 `SubprocessRuntime` 与文件系统适配，所有远程操作通过 `/bin/bash -l -c` 经 `quoteE2BShellArg` 转义后执行。
依赖方向单向向下：具体实现依赖抽象包，跨族之间仅通过 cordis Context 注入（如 subprocess-e2b 注入 e2b），不直接耦合。
