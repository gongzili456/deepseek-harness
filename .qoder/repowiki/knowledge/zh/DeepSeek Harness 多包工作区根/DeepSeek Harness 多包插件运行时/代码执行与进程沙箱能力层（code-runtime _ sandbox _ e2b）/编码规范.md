- 每个能力包通过 `declare module '@deepseek-ai/cordis'` 扩展 Context 接口（codeRuntime、sandbox、e2b、subprocess），将实现注册为同名 Service。
- 配置对象统一以 `static Config: z<object>` 声明并通过 schemastery 填充默认值，构造期再对数值字段做正数/安全整数等语义校验。
- 对外暴露的抽象类继承自 `Service`，并通过 `ctx.effect(() => teardown, '...')` 在 service 销毁时自动回收资源（worker 终止、ACL grant 撤销、E2B sandbox kill）。
- 跨进程/跨世界通信采用「严格白名单消息解析」：入站消息先被 parse 函数逐字段类型校验，未知或畸形消息静默丢弃，避免模型代码破坏宿主。
- 输出与错误统一收敛为 `CodeRunResult` 中的 error 字段（kind 枚举 exception/timeout/output-limit/abort/invalid-output/worker-exit），而非抛异常，使调用方可区分运行期失败与服务契约误用。
- 每个包均导出独立的 `./invariant` 子路径供内部断言使用，并在 package.json 的 exports 中显式声明该子路径的类型与默认入口。
