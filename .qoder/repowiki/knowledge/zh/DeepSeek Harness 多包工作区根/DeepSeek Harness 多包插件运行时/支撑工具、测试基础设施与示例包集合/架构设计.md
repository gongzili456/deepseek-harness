本模块由四个并列的 package 组构成，彼此通过 npm 包名解耦：
- `packages/util/`：零依赖原子工具集，每个子包（brand、home-paths、timeout、atomic-write、native-command、output-retention、launch-environment）遵循统一结构——`src/index.ts` 暴露纯函数/类型，`src/invariant.ts` 作为 Cordis 插件向 `@deepseek-ai/dsh-invariants` 注册运行时契约检查；无业务语义，仅被上层 capability 消费。
- `packages/runtime-diagnostics/invariants/`：提供 `InvariantRegistry` Service，基于 allowlist/blocklist 正则过滤按包名启用/禁用各包的 invariant 安装器，并通过 `ctx.plugin` 在独立 fiber 中执行，失败抛出带 `packageName` 的 `InvariantError`。
- `packages/test-support/`：开发期支撑包，不对外暴露产品 API；按职责拆分为 acp-snapshot（四层架构：launcher/harness/normalize/suite）、agent-loop-testkit、client-runtime、llm-mock-server（OpenAI 兼容 mock CLI）、llm-replay、loader-smoke，其中 acp-snapshot 直接依赖 vitest，只能在测试环境导入。
- `packages/examples/`：预组装的可运行 Bundle（acp-demo、agent-spine-demo、jsonrpc-demo），通过 `apply(ctx, config)` 以有序生命周期组合 spine/persistence/query/transport 等插件，使用 schemastery 声明 Config 并导出供 Loader 加载。
依赖方向单向：examples → test-support / util；test-support 可引用 util 和 runtime-diagnostics；util 与 runtime-diagnostics 之间无相互依赖。
