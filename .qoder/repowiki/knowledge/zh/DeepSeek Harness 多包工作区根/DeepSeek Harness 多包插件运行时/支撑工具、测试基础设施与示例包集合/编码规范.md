- 每个 util 子包采用 `src/index.ts` + `src/invariant.ts` 双文件结构，前者暴露纯 API，后者作为 Cordis 插件向 invariants 服务注册该包的运行时契约检查。
- invariant 安装器统一通过 `ctx.invariants.register(PACKAGE_NAME, installer)` 注册，并以 `@deepseek-ai/<pkg>` 形式的完整 npm 包名作为 owner 标识。
- Config 定义统一使用 `@deepseek-ai/schemastery` 的 `z.object({...})` 声明，并在同一文件中导出同名 `Config` 类型与 schema 常量。
- 插件应用函数统一命名为 `apply(ctx: Context, config: ...)`，并通过 `ctx.effect(async function* () { ... yield plugin.dispose })` 管理有序生命周期与反向释放。
- 示例 Bundle 通过命名导出 `name`、`Config`、`apply` 暴露给 Loader，且明确避免 stdout 日志以保持传输通道纯净。
- 测试目录与源码一一对应（`tests/*.spec.ts` 对应 `src/*.ts`），fixture 数据集中放在 `tests/fixtures/` 下并按场景分目录组织。
