- 每个能力包都通过 `declare module '@deepseek-ai/cordis'` 扩展 Context 接口（`ctx.web`、`ctx.attachments`、`ctx.spillStore`），将服务挂载到统一上下文键。
- 抽象服务类继承自 `@deepseek-ai/cordis` 的 `Service`，并在构造函数中以固定名称注册（如 `'web'`、`'attachments'`、`'spillStore'`）。
- 插件入口统一导出 `name`、`inject` 依赖数组、`Config`（schemastery schema）和 `apply(ctx, config)` 函数，由 Cordis 加载器发现并装配。
- 配置字段通过 schemastery 提供默认值，并在 `apply` 中用 `assertPositiveInteger` / `assertPositiveFinite` 等断言函数做运行时校验。
- provider 实现必须暴露 `id`、`available()` 与能力方法（search/fetch/saveText），由 seam 在调用时按规则解析，避免顺序依赖。
- 对外错误统一封装为自定义错误类型（`WebError`、`AttachmentError`），携带稳定错误码（如 `WEB_DUPLICATE_PROVIDER`、`IMAGE_TOO_LARGE`、`ATTACHMENT_CORRUPT`）以便上层诊断。
