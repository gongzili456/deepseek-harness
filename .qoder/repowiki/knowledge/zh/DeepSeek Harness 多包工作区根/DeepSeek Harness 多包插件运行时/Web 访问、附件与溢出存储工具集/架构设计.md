本模块按能力划分为三个独立子域，每个子域遵循「抽象服务 + 具体实现 + 策略/工具」的分层模式：
- Web 访问（packages/web）：`web` 包通过 `WebRuntime` 在 `ctx.web` 上暴露统一的搜索/抓取 seam，维护 search/fetch 两个 provider 注册表并按「配置优先 → 唯一可用自动选择 → 报错」规则解析；`web-fetch-http`、`web-search-deepseek`、`web-search-exa`、`web-search-perplexity` 作为插件调用 `registerFetchProvider` / `registerSearchProvider` 注入；`tool-web` 是模型侧工具包装层，仅持有 schema、提示词与输出格式，不依赖具体 provider。
- 附件存储（packages/attachment）：`attachment` 包定义 `AttachmentStore` 抽象（validateImage/saveImage/readImage），`attachment-local` 基于 SHA-256 内容寻址、原子 link 与目录 fsync 实现本地磁盘后端，二者通过类型与错误码解耦。
- 溢出存储（packages/spill）：`spill` 包定义极简 `SpillStore.saveText` 抽象；`spill-local` 提供基于 OS tmpdir 的会话隔离文件系统实现；`spill-policy` 作为 `tools/post-execute` 监听器，在结果超限时调用 `ctx.spillStore` 并替换为 head/tail 预览 + locator，同时处理 `tools/code-dispatch-log` 以限制日志副本大小。
依赖方向严格单向：tool-web → web seam → 各 provider；policy → spill-store 抽象；local 实现只依赖对应抽象包，不存在反向依赖。所有 provider 均遵守 AGENTS.md 中「拒绝重定向」的安全约定。
