packages/ 是 DeepSeek Harness 的 monorepo 根，按职责拆分为 core（core_runtime）、session_lifecycle、storage_backends、web_tools、capability_shell_fs、capability_code_sandbox、capability_lsp_skill、capability_subagent_workflow_jobs、llm_identity_credentials、product_features、platform_integrations、host_client_sdk、boot_settings_workspace_context、support_infra 等子模块；各子模块通过共享的 typert 类型驱动 RPC 契约与 Cordis 服务注册机制进行跨包通信——能力层（shell/fs/sandbox/e2b/lsp/skill/compaction/subagent/workflow/jobs）在 boot 阶段向上下文暴露 ctx.* seam，product_features 与 platform_integrations 作为插件消费这些 seam，host_client_sdk 与 api 则把同一套服务桥接到宿主进程与外部客户端。所有包均遵循 Cordis 插件约定：定义接口 → 提供默认实现 → 通过 @cordis/plugin 注解注册到运行时上下文键，从而保证任意包可被替换或禁用而不影响其他能力。
