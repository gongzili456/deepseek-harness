- 每个 RPC 领域以 `*.schema.ts` 声明 Zod schema、`*.ts` 实现接口，并在 `rpc-map.ts` 的 `RpcMethodMap` 中集中注册方法签名，使请求/响应类型全部从签名推导。
- 宿主插件统一导出 `name`、`inject`、`Config` 与 `apply(ctx, config)` 四个命名导出，以便 Cordis Loader 自动发现并装配。
- 跨进程/跨边界的配置对象一律用 schemastery/Zod Schema 声明并附带默认值，在插件 `apply` 入口处消费已解析的配置。
- 敏感方法通过集中白名单（如 `PRIVILEGED_METHODS`）配合 `isTrustedApiRequest` 进行 loopback 信任校验，拒绝非受信来源的请求。
- 异步资源清理通过 `ctx.effect` 注册副作用，并在 effect 返回的 dispose 函数中执行关闭逻辑（如 WebSocket downlinks、transport.close）。
- ACP 桥对会话状态使用本地 Map 记录 `SessionRecord`，并通过 `inflight` 槽位与 `whenIdle` 协同确保 prompt 请求的精确结算与竞态安全。
