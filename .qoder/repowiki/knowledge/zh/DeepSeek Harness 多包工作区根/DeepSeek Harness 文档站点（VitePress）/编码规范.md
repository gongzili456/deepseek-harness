- 新增文档页统一通过 `pairedPages([...])` 或 `mirroredPages([...])` 声明，而非直接写入 `docsPages`，以同时产出 zh-CN 与 en-US 两个 locale 的路由。
- 每篇文档在声明中显式指定 `sidebar`（如 `zh-guide` / `en-guide`）、`section`（中文/英文分组名）和 `order`，由 `orderedPages` 与 `sectionSpec` 共同决定侧边栏分组与排序。
- 导航与侧边栏条目不手写静态链接，而是通过 `routeLink(route)` 与 `landingLink(locale, collection)` 从 manifest 动态派生，保证重命名/重排后链接仍正确。
- locale 差异值（label、source、contentLocale、sidebar、section）统一用 `{ root: ..., en: ... }` 对象表达，并由 `localized()` 在运行时按当前 locale 取值。
- VitePress 配置通过 `sharedTheme` 抽取中英文共用的 search、socialLinks、editLink 等主题设置，再在各 locale 的 `themeConfig` 中叠加本地化文案。
- Markdown 渲染器通过重写 `text` 与 `code_inline` 规则对 `{{` / `}}` 进行 HTML 转义，防止 Vue 插值语法被误解析。
