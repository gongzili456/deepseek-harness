站点以 `.vitepress/config.ts` 为唯一入口，通过 `withMermaid` 插件启用 Mermaid 图表，并声明 `srcDir: '.generated'`、`publicDir: '../public'`，使实际源码位于工作区根目录的 `docs/`、`scripts/project-doc-site.ts` 等位置。
- 路由与侧边栏由 `docs.ts` 集中维护：定义 `DocsPage`、`DocsSidebar`、`DocsSection` 等类型，并通过 `pairedPages` / `mirroredPages` 工具函数把成对的中文/英文 Markdown 映射到 `root` 与 `en` 两套 locale；按 `homeAndGuide`、`develop`、`cordisTutorial`、`subsystemsReference`、`reference` 等模块聚合出完整的 `docsPages` 清单。
- `config.ts` 中的 `sidebar()` 根据 `orderedPages(locale, collection)` 按 `sectionSpec` 定义的分组顺序生成 VitePress 侧边栏，导航栏通过 `landingLink()` 自动指向集合首项，避免硬编码路径。
- 开发时通过自定义 Vite 插件 `deepseek-harness-doc-projector` 调用 `watchCanonicalDocs` 监听 `docsSourceFiles()` 返回的源文件变更并重新执行 `projectDocs()` 刷新 `.generated` 树。
- 主题层使用默认 VitePress 主题，通过内联 `siteStyle` CSS 与 `scrollbarScript` 定制 logo、标签、滚动条行为；搜索、编辑链接、社交链接集中在 `sharedTheme` 中复用。
- 依赖方向单向：`config.ts` → `docs.ts` → `../../scripts/project-doc-site.ts`，网站本身不持有业务逻辑，仅负责文档发布。
