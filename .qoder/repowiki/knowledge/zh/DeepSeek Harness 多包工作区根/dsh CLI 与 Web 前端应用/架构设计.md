本模块包含两个并列的应用子包：
- `apps/cli`：通过 `package.json` 的 `bin.dsh` 暴露 `lib/bin.js` 作为可执行入口；`src/bin.ts` 使用 Commander 解析参数后按 `mode`（`profile` / `plugin` / `dump-config`）动态 `import()` 对应处理器（`profile-boot.ts`、`plugin.ts`、`dump-config.ts`），避免无关模式被加载进进程；CLI 依赖大量 `@deepseek-ai/dsh-*` workspace 包组合出 Cordis 插件树，并通过 `config/agent-presets/{minimal,standard,code,cordis}` 下的 `preset.yml` + `agent.cordis.yml` 提供预置 Agent 配置。
- `apps/web`：极薄的 Vite 应用，`src/main.ts` 仅实例化 `@deepseek-ai/dsh-client-web` 的 `AppWebEntry` 并挂载到 `#root`；`vite.config.ts` 通过自定义 Rollup `manualChunks` 将 KaTeX/Shiki/Micromark 等重型依赖拆入 `vendor` 块，语法高亮 grammar 单独归入 `assets/langs/`，字体归入 `assets/fonts/`；同时用 alias 把 `@deepseek-ai/dsh-client-web*` 等指向源码目录以走 Vite CSS 管线，并用 `define` 注入 `process.versions.node='0.0.0'` 屏蔽 Node-only 分支，禁止独立 `vite serve` 运行（需经 `dsh web` 注入 `window.__DSH_BOOT__`）。
- 测试层：`apps/web/tests/*.e2e.ts` 统一通过 `tests/scaffold.ts` 中的 `launchWebScaffold` 启动真实 Cordis 组合（base + web-app bundle patches 覆盖空 profile 根），按 `$DSH_SNAPSHOT` 环境变量在 replay/record/refresh 三种模式下驱动 Playwright 浏览器，并以 `tests/snapshots/**/ui.expected.md` 做 aria 快照断言；CLI 侧 `apps/cli/tests/*.spec.ts` 针对 args 解析、进程关闭、MCP 配置等单元行为。
