- CLI 入口按 `mode` 分派后使用 `await import('./xxx.ts')` 动态加载处理器，使每个命令路径只加载自身依赖。
- Web 测试统一通过 `launchWebScaffold` 装配 base + web-app bundle patches 并覆写 persistence/skill-root/webserver 等行，所有场景共享同一套真实组合而非 mock。
- Web e2e 快照以 `*.expected.md` 形式提交，并在 `compareOrRefreshGolden` 中经 `normalizeAria` 剔除 UUID、cwd、时长、吞吐等不稳定字段后再比对。
- Vite 构建通过 `manualChunks` 白名单（`VENDOR_PACKAGES`）与 `BOOT_GRAMMAR_FILES` 精确控制 vendor 与 langs chunk 归属，保持 React 代码留在 index 以便热更新。
- CLI 参数解析使用 Commander 的 `allowUnknownOption` + `passThroughOptions`，把未知参数透传给被启动的 profile，实现 launcher 与 app 各自持有 `--help`。
