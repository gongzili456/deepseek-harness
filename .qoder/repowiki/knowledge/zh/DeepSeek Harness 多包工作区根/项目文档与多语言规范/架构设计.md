本模块为纯文档仓库，按主题划分为若干子目录：`subsystems/` 描述各子系统（session、tools、storage、sandbox 等）；`cordis-tutorial/` 提供分步教程（01-07）；`cordis-api/` 记录 Cordis API；`user/` 面向用户的开发与使用指南；`cookbook/` 收录扩展实践；`postmortem/` 以编号化文件记录事故复盘；根目录存放顶层概念文档（architecture、development、testing、glossary 等）。每个 `.md` 均配有同名的 `.zh.md` 中文镜像和 `.i18n.yaml` 一致性记录，三者构成不可分割的“三元组”；`.i18n.yaml` 通过记录两端文件的 git blob hash 实现内容级同步校验，由 `pnpm run verify-translation-pairing` 在 CI 中强制约束。`i18n/` 子目录集中定义翻译规则、术语表与风格样例，作为所有文档对的语言契约。该模块不产出可执行代码，仅通过脚本与 Git merge driver 保证多语言一致性。
